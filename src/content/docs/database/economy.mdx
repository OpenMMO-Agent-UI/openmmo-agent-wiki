## 貨幣

只有一種貨幣,伺服器內部存成一個銅幣整數。顯示時換算:

**1 金 (g) = 100 銀 (s) = 10,000 銅 (c)**

新角色**沒有起始金錢**,第一筆收入要靠賣掉怪物掉落物。起始武器是
**{itemName('worn_iron_sword')}**,故意設計成**沒有標價** —— 商人不收,
所以不能靠反覆創角色換錢。

商店的品項是**刻意保持精簡**的。設計原則:只賣「第一階地城不會確定掉落」的部位,
當作運氣太差的玩家的保險。確定掉落的東西不需要保險,高階部位則要保護打寶循環。

所以 **{itemName('leather_helmet')}**(古墓的確定掉落)、
**{itemName('iron_sword')}** 這類東西**不會出現在商店**。

### 賣錯了可以買回來

賣給商人的東西,最近 **10 件**可以用原價買回 —— 就是賣掉的金額,不多不少。
這是給誤賣用的補救,來回是金錢中性的,所以不影響價差結構
(用議價賣高的東西,買回來也一樣貴)。

清單是「角色 × 商人」各自保存的,重新連線也還在、沒有時間限制,
但**伺服器重啟就會消失**。

### 商人擺攤(/lay_stall)

商人職業可以打 `/lay_stall` 在戶外攤開一張矮桌當作攤位視覺標記,
`/pack_stall` 收起(登出也會自動收攤,一人限一個、只能在戶外)。

攤位不再只是場景道具 —— **點擊別人擺出來的攤位會直接開啟交易視窗**,
不用先送邀請、對方也不用同意。完整規則見[玩家交易](../../guides/trade/)。

## 議價

Rica 是 LLM 驅動的 NPC,**可以用對話殺價**。但價格保護全部在伺服器端:

1. 伺服器先算出價格帶 `[最低價, 最高價]`,由基準價、價差、**CHA 加成**決定。
2. LLM 只能在帶內選一個調整幅度,不能給絕對價格。超出範圍會被夾住或拒絕。
3. 伺服器保證**永遠套不了利** —— 最大折扣的買價一定高於最高的賣價。
4. 有每日預算和冷卻:商人每遊戲日 1 金、每位玩家 40 銀,議價冷卻 **30 秒**,
   談成的優惠**只能用一次、5 分鐘後失效**。

CHA 越高,伺服器給的價格帶越寬(約 ±5～25 個百分點) —— 所以魅力高的角色真的比較會殺價。

談成優惠後,商人除了在交易視窗顯示,也會用系統訊息在聊天室講出來(折扣或加價幅度、對象、有效時間)——不用打開交易視窗才知道有優惠在等你。商人偶爾也會不等你開口殺價,主動遞出一個折扣。

:::tip
講個好故事、帶點消息、適度奉承,Rica 真的會給折扣。反過來,態度惡劣也可能被**加價** ——
這是對稱的,而且符合她的人設。
:::

### 不想被推銷?按「現在不要」

NPC 主動推來的交易或優惠視窗,現在多一個「現在不要」可以按;放著不理、讓提示逾時消失也算拒絕。
拒絕之後,**同一個 NPC 10 分鐘內不會再對你推播**交易邀約或優惠。

## 非商人 NPC

不是只有商人能交易。衛兵 **Karl** 有自己的願望清單,
會用**基準價的 {karl.wishlistRatePercent}%** 收購他要的東西:

<FilterTable
  placeholder="搜尋…"
  columns={[
    { key: 'npc', label: 'NPC' },
    { key: 'wants', label: '想要的東西' },
    { key: 'rate', label: '收購價', align: 'right' },
    { key: 'value', label: '實際金額', align: 'right' },
    { key: 'ricaSell', label: '賣給 Rica', align: 'right' },

    return {
      npc: karl.npcName,
      wants: itemName(id),

      value: formatCoins(i?.basePrice ? Math.floor(i.basePrice * karl.wishlistRatePercent / 100) : null),
      ricaSell: formatCoins(sellPrice(i?.basePrice ?? null, rica.sellRatePercent)),
    };
  })}
/>

**從 Rica 買來、賣給 Karl 是有賺頭的** —— 這是刻意保留的內容,
等於自然發生的跑腿任務。規模被 Karl 的錢包上限
({formatCoins(karl.walletCap)})卡住,不會失控。他的錢來自每遊戲日
{formatCoins(karl.salaryPerDay)} 的薪水,存滿上限就停發。

要注意的是他**只在願望清單沒被滿足時才會買** —— 背包裡已經有的東西就不想要了。

Karl 身上那把長槍和整套皮甲是**配發裝備**,上線時自動補發穿上,不算掉落物 ——
這類裝備**不能販售**,不管是他賣給你還是你賣給他,免得靠上下線反覆刷裝備變成金幣水龍頭。

### NPC 記得你(好感度)

LLM 驅動的 NPC 會保留最近的對話(最近 30 行,附遊戲內時間戳),
所以同一段對話跨好幾輪也不會前言不對後語;吟遊詩人另外還記得自己最近彈過的 8 首歌,避免一直重複。

對話同時會累積一個**好感度**數值,LLM 每回合最多調整 ±1、總計上限 ±5,
存在伺服器端。好感度到門檻的熟客,才會被 NPC 排進「私下交易」的對象名單——
這就是下面「珍藏品」機制背後真正在算的東西。

### 珍藏品(keepsakes)

非商人 NPC 的部分持有物是**珍藏品** —— 瀏覽他們的物品時根本不會出現,
開口要買也會被回絕。只有 NPC 主動對某位玩家**私下開價**,對方才能在
報價有效的幾分鐘內買走一件;賣掉之後過段時間會補回。
目前的例子是吟遊詩人 Signe 的鍍金曼陀林 ——
怎麼成為她願意開價的熟客,見[音樂與吟遊詩人](../../guides/music/)。

打倒怪物時,除了牠身上的武器之外,還有機率直接掉出這些東西:

但期望要打 100 隻。

## 錢從哪來

遊戲刻意讓金錢流入受控。可重複的來源只有三個:

| 來源 | 金額 |
|---|---|
| 錢幣堆(地城寶箱) | 1–10 銅 |
| 地城寶箱金幣 | 深度 × 500 ～ 深度 × 1500 |
| 釣魚 | 每次期望 8–24 銅 |

對照 NPC 衛兵的日薪是 {formatCoins(karl.salaryPerDay)}。

怪物掉的武器**大多是無法販售的「磨損」版本**,這是刻意的 ——
高階武器如果能從一般怪物身上穩定變現,就會變成印鈔機。
一般帶武器的怪物掉落率只有 10%,頭目才是確定掉落。
