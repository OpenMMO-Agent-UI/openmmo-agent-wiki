**獸人督軍**的落差很大 —— 生命 120 是資料裡直接指定的(不是等級推算的 45),
Guard 13、命中 +6、傷害 2d8。獸人巢穴有 10 層,建議先把皮甲一套湊齊再下去。

頭目死亡後不會用計時器重生 —— 牠所在的樓層會卡住,直到當天的**日落地城重置**
(每個遊戲日一次)才會復活;重置同時會把還留在該地城裡的所有人傳送回入口,
並伴隨一聲遠方的吼叫。開寶箱不再要求打死頭目或站在牠身邊 —— 見下方
「鑰匙與鎖住的樓層」。頭目原本親自掉落的武器(哥布林短劍、鐵劍、精鋼長劍)
也已經改成寶箱的確定掉落,見下表。

## 鑰匙與鎖住的樓層

每座地城**每 5 層**的樓梯間出口都有一道強制存在的鎖門,把去路完全擋住:

<FilterTable
  placeholder="搜尋地城…"
  columns={[
    { key: 'name', label: '地城' },
    { key: 'floors', label: '鎖住的樓層' },
    { key: 'chest', label: '開寶箱要用的鑰匙' },
  ]}
  rows={dungeons
    .filter((d) => d.keyPrefix)
    .map((d) => {
      const locked = lockedFloors(d);
      return {
        name: dungeonName(d),
        floors: locked.map((f) => `${f} 層`).join('、'),
        chest: itemName(`${d.keyPrefix}_${locked[locked.length - 1]}`),
      };
    })}
/>

- **鑰匙掉在鎖門前一段樓層**(例如獸人巢穴 1–4 層掉 5 層的鑰匙,6–9 層掉 10 層的鑰匙)。
  該段的怪物被打死時有 **5%** 機率掉落對應鑰匙,打破木桶、木箱或雜物箱則是 **1%**。
  同一角色已經持有那把鑰匙,或今晚已經開過該地城的寶箱,就不會再擲。
- 鑰匙掉在地上,誰撿到算誰的;**5 層的鑰匙打不開 10 層的門**。
- 拿著鑰匙點鎖著的門就能打開,**鑰匙不會被門消耗**,死掉或離開再回來一樣能用,
  也沒有使用期限。門打開後會**維持 30 秒才自動關閉**,沒鑰匙的人可以趁這段時間跟著溜進去,
  但門一關上,裡面的人一樣打不開,只能繼續往下走。
- **地城最深一道鎖門的鑰匙**(古墓 5 層、獸人巢穴 10 層、食人魔要塞 15 層)是開寶箱的門票 ——
  只要拿著它站上最底層就能開寶箱,不必打死頭目;開啟的瞬間會消耗掉該地城**手上持有的每一種**
  鑰匙各一把。頭目仍然守在寶箱旁,想安全開箱通常還是得先解決牠。

## 寶箱掉落規則

每座地城的寶箱掉落分三部分:

1. **確定掉落(signature)** —— 每座地城固定給一到兩件,就是上表的「確定掉落」欄;
   三座地城的頭目武器現在也算在裡面。
2. **獨立擲骰** —— 該階級池裡的其他裝備,每件各自用自己的機率擲一次。
3. **低階補償** —— 階級比地城低的裝備各有額外 10% 機率,讓你在高階地城補齊漏掉的部位。

金幣是 `深度 × 500 ~ 深度 × 1500`。

設計目標是**平均約 5 次**湊齊該階級首次出現的部位。

<FilterTable
  placeholder="搜尋裝備…"
  columns={[
    { key: 'name', label: '裝備' },
    { key: 'en', label: '遊戲內名稱' },
    { key: 'tier', label: '寶箱階級', align: 'center' },
    { key: 'chance', label: '掉落機率', align: 'right' },
    { key: 'guard', label: 'Guard', align: 'right' },
    { key: 'cha', label: 'CHA', align: 'right' },
    { key: 'effect', label: '效果' },
  ]}
  rows={items
    .filter((i) => i.chestTier)
    .sort((a, b) => a.chestTier - b.chestTier || (b.guard ?? 0) - (a.guard ?? 0))
    .map((i) => ({
      name: itemName(i.id),
      en: i.name,
      tier: `T${i.chestTier}`,
      chance: i.chestChance ? `${Math.round(i.chestChance * 100)}%` : '確定掉落',
      guard: i.guard ?? '—',
      cha: i.chaBonus ? `+${i.chaBonus}` : '—',
      effect: i.hasSustenance ? '飽食消耗 ×0.75' : '—',
    }))}
/>

:::note[寶箱裡的武器只有三座地城的頭目武器]
武器原則上走「拿著那把武器的怪物掉落」的路線,例外是哥布林短劍、鐵劍、精鋼長劍 ——
這三把頭目武器現在改成各自地城寶箱的確定掉落,頭目本身不再掉落。其餘武器一律看怪物
拿什麼就知道能打到什麼,寶箱不給。
:::

## 地城裡的其他東西

- **木桶與木箱可以打破** —— 點一下,角色會走過去揮一刀。寶箱不會被打破。
- **寶箱要用開的** —— 點下去角色會走過去掀開蓋子,前方會掉出一堆錢幣,
  撿起來直接進錢包(1–10 銅),不佔背包格。
- **走廊有門** —— 走廊通進房間的開口有木製雙開門,點擊開啟。
- **走廊和房間的牆不一樣** —— 房間是中世紀石磚,走廊是岩壁,可以用來辨認自己在哪。
