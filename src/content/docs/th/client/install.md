## การเปิดครั้งแรก

### macOS —— เปิดได้เลย

**เวอร์ชัน macOS เซ็นด้วย Apple Developer ID ผ่านการ notarize จาก Apple และ staple ตั๋วไว้ในแอปแล้ว** แตกไฟล์ ดับเบิลคลิก แล้วมันจะรันโดยไม่มีคำเตือนจาก Gatekeeper

คุณไม่ต้องคลิกขวา → Open และไม่ต้องใช้ `xattr -cr` —— คำแนะนำที่หาเจอในอินเทอร์เน็ตสำหรับแอปที่ไม่ได้เซ็น ใช้กับเวอร์ชันนี้ไม่ได้

### Windows —— คลิกเพิ่มหนึ่งครั้ง

**เวอร์ชัน Windows ไม่ได้เซ็น** ดังนั้น SmartScreen จะขึ้นว่า “Windows protected your PC” กด **More info** → **Run anyway**

ใบรับรองสำหรับเซ็นโค้ดมีค่าใช้จ่ายทุกปี และปัจจุบันมีเพียงใบเดียวสำหรับ macOS ถ้าโครงการนี้มีประโยชน์กับคุณ [การสนับสนุน](https://ko-fi.com/dakywang) ช่วยให้ใบรับรองสำหรับ Windows เป็นไปได้

### Linux —— ตั้งบิตให้รันได้

AppImage ไม่มีการเซ็นที่พูดถึงได้ แค่ต้องให้รันได้ก็พอ:

```bash
chmod +x openmmo-agent-*linux-x64.AppImage
./openmmo-agent-*linux-x64.AppImage
```

## การเริ่มใช้ครั้งแรก

สี่หน้าจอตามลำดับแล้วคุณก็อยู่ในเกม **ไม่มีขั้นตอน “เล่น” แยก** —— เลือกตัวละครคือเข้าเล่นทันที

### 1. เซิร์ฟเวอร์ —— เลือกโปรไฟล์การเชื่อมต่อ

โปรไฟล์ `openmmo.to.nexus` ที่ติดมาด้วยนั้นตายตัว และเป็นตัวที่ผู้เล่นส่วนใหญ่ต้องการ

โปรไฟล์หนึ่งผูกสามสิ่งไว้ด้วยกัน: URL ของเซิร์ฟเวอร์ ต้นทางของไฟล์ภูมิประเทศ และ Google client ID กับ secret ทั้งสามต้องเดินทางไปด้วยกัน เพราะเซิร์ฟเวอร์รับเฉพาะโทเคนเข้าสู่ระบบที่ออกโดย client ID ที่อยู่ในรายการอนุญาตของตัวเองเท่านั้น ถ้าคุณรันเซิร์ฟเวอร์เอง คุณสร้าง แก้ไข คัดลอก และลบโปรไฟล์ได้ และทดสอบการเชื่อมต่อก่อนใช้ได้ด้วย

### 2. เข้าสู่ระบบ —— device flow ของ Google

กดปุ่มแล้วจะมีรหัสปรากฏขึ้น ให้กรอกในเบราว์เซอร์ ถ้ามีข้อมูลรับรองที่แคชไว้แล้ว ระบบจะข้ามไปขั้นถัดไปเลย

### 3. ตัวละคร —— เลือกหรือสร้าง

มีสองแท็บ:

- **เลือกตัวละครของคุณ** —— ได้สูงสุด 3 ตัวต่อบัญชี (เซิร์ฟเวอร์บังคับ) คลิกเพื่อเข้าเล่น หรือลบ
- **สร้างตัวละครใหม่** —— ชื่อ อาชีพ เพศ จะถูกซ่อนเมื่อถึงเพดานแล้ว

### 4. เกม

โหมดถูกกำหนดให้คุณตอนเข้า: **อัตโนมัติถ้ามี backend ของ LLM ตั้งไว้และผ่านการตรวจสอบ ไม่เช่นนั้นเป็นโหมดมือ** ถ้าโหมดอัตโนมัติเริ่มไม่สำเร็จ จะถอยไปเป็นโหมดมือ คุณสลับได้ทุกเมื่อจากแถบด้านบน

## สองโหมดการเล่น

เซิร์ฟเวอร์อนุญาตเซสชันควบคุมต่อหนึ่งตัวละครเพียงเซสชันเดียวเท่านั้น ดังนั้นสองโหมดจึงไปถึงจุดนั้นด้วยวิธีต่างกัน

**โหมดมือ** คือการเชื่อมต่อโดยตรง —— เว็บไคลเอนต์ OpenMMO ที่ฝังอยู่เข้าสู่ระบบด้วยบัญชี Google ของคุณเองและคุยกับเซิร์ฟเวอร์ตรงๆ เหมือนเล่นในเบราว์เซอร์เลย ไม่มีตัวรีเลย์ ไม่มี `agent-client`

**โหมดอัตโนมัติ** จะเปิด `agent-client` ซึ่งต้องใช้เซสชันเดียวนั้นเป็นของตัวเอง —— ดังนั้นการ “ดู” จึงไม่สามารถทำได้ด้วยการเข้าสู่ระบบอีกบัญชีข้างๆ แทนที่จะทำอย่างนั้น จะมีตัวรีเลย์วางอยู่บน loopback:

```
agent-client <--ws--> proxy (127.0.0.1) <--wss--> openmmo.to.nexus
                        |
                        +--> ผู้ชม (/mirror)
```

เซิร์ฟเวอร์ไม่รู้เลยว่ามีอะไรอยู่ข้างหลัง agent การอยู่ตรงกลางทำให้ตัวรีเลย์ส่งต่อทุกข้อความจากเซิร์ฟเวอร์ไปยังหน้าจอผู้ชมแบบอ่านอย่างเดียวได้ **ตัวรีเลย์ฟังที่ `127.0.0.1` เท่านั้น จึงไม่มีอะไรออกจากเครื่องคุณ**

## หน้าจอเกม

แถบด้านบนแสดงสถานะการเชื่อมต่อ ค่าสถานะ การใช้หน่วยความจำของหน้าจอผู้ชม ปุ่มโหลดภาพ 3D ใหม่ สวิตช์มือ/AI และปุ่มเปลี่ยนตัวละครหรือเซิร์ฟเวอร์ ถ้าแก้ตั้งค่าขณะ agent กำลังทำงาน ปุ่ม **ใช้งานและเริ่มใหม่** จะปรากฏขึ้น

แถบซ้ายเปิดลิ้นชักหกช่อง:

| ลิ้นชัก | แสดงอะไร |
|---|---|
| อุปกรณ์ | สิ่งที่สวมอยู่ ทีละช่อง |
| กระเป๋า | สิ่งที่พาไป และไอเทมที่ agent ขายหรือทิ้งได้ |
| บุคลิกและความจำ | prompt เฉพาะของตัวละครนี้ (แก้ได้) และสิ่งที่ agent จดไว้ (อ่านอย่างเดียว) |
| พิกัด | ที่คั่นสถานที่ รวมถึง “ใช้ตำแหน่งปัจจุบัน” |
| ชุดคำสั่งที่บันทึกไว้ | คำสั่งที่ใช้บ่อย บันทึกเป็นปุ่มกดครั้งเดียว |
| กิจกรรม | สองแท็บ: ความคิด (ทุก prompt และคำตอบ) และบันทึก (ผลลัพธ์จากโปรเซส agent) |

รายละเอียดของแต่ละลิ้นชักอยู่ใน[คู่มือแผงควบคุม](../panel/)

**สั่งงาน** ที่ติดอยู่ใต้ภาพเกม เป็นการควบคุมเดียวที่ส่งถึง agent ที่กำลังทำงาน: พิมพ์คำสั่งแล้วมันจะไปถึงเป็นเทิร์นถัดไปของตัวละคร **แบบพยายามให้ดีที่สุด —— ไม่รับประกันว่าจะถูกทำตาม**

## กุญแจของคุณเก็บไว้ที่ไหน

API key และ secret ของโปรไฟล์การเชื่อมต่อถูกเข้ารหัสด้วย keychain ของระบบปฏิบัติการ (`safeStorage` ของ Electron และมี AES-GCM เป็นทางเลือกสำรอง) แล้วส่งให้ agent เป็นตัวแปรสภาพแวดล้อม —— **ไม่เคยเขียนลงใน `config.toml`** ไฟล์ตั้งค่าที่แปะไปในรายงานบั๊กจึงไม่มีข้อมูลรับรองติดไปด้วย

## การแก้ปัญหา

**เวอร์ชันโปรโตคอลไม่ตรงกัน** —— เซิร์ฟเวอร์อัปเดตแล้ว ไปเอาเวอร์ชันใหม่ที่[หน้าดาวน์โหลด](../download/)

**แก้ตั้งค่าแล้วไม่มีอะไรเกิดขึ้น** —— agent อ่านไฟล์ตั้งค่าครั้งเดียวตอนเริ่มทำงาน กด **ใช้งานและเริ่มใหม่** ที่แถบด้านบน

**เปิดจากเทอร์มินัลของ VS Code แล้วไม่ขึ้นเลย** —— ตัว VS Code เองก็เป็นแอป Electron และปล่อย `ELECTRON_RUN_AS_NODE=1` รอดออกมา ทำให้ไคลเอนต์ถูกเริ่มเป็น Node เปล่าๆ:

```bash
env -u ELECTRON_RUN_AS_NODE npm start
```

**มีอะไรหายไปหรือค้างอยู่ในหน้าจอผู้ชม** —— หน้าจอผู้ชมของโหมดอัตโนมัติเริ่มจาก snapshot ดังนั้นสิ่งที่ agent รู้จักแต่ไม่ได้กำลังติดตามอยู่ จะค่อยๆ ปรากฏขึ้นเมื่อกลับเข้ามาในระยะมองเห็น
