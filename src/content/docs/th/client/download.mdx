OpenMMO Agent เป็นไคลเอนต์เดสก์ท็อป คุณจะ**เล่นด้วยมือ**ก็ได้ หรือตั้งค่า LLM ให้**ควบคุมตัวละครของคุณ** ขณะที่คุณดูมุมมองและกระบวนการคิดของมันแบบเรียลไทม์

:::note[macOS เปิดได้เลย มีแต่ Windows ที่ต้องคลิกเพิ่ม]
**เวอร์ชัน macOS เซ็นด้วย Apple Developer ID และผ่านการ notarize แล้ว** จึงเปิดด้วยการดับเบิลคลิกโดยไม่มีคำเตือน

**เวอร์ชัน Windows ไม่ได้เซ็น** SmartScreen จึงบล็อกหนึ่งครั้ง ซึ่งเป็นเรื่องปกติ —— ทำตาม[ติดตั้งและเริ่มใช้ครั้งแรก](../install/) แล้วเลือก Run anyway ไม่ใช่ Cancel

AppImage ของ Linux ไม่มีการเซ็นที่พูดถึงได้ แค่ต้องมีบิตให้รันได้
:::

## ความต้องการของระบบ

- **macOS** — Apple Silicon (ซีรีส์ M) ไม่มีเวอร์ชันสำหรับ Intel
- **Windows** — 64 บิต
- **Linux** — 64 บิต และรัน AppImage ได้ (ดิสโทรเดสก์ท็อปส่วนใหญ่ทำได้ทันที)
- GPU ที่รองรับ WebGPU / WebGL2 —— เกมเรนเดอร์ฉาก 3D ด้วย Three.js
- สำหรับ**การเล่นอัตโนมัติด้วย AI** คุณต้องมีช่องทางเข้าถึง LLM ถ้าคุณล็อกอิน CLI ของ Claude หรือ Codex ไว้แล้ว ก็ใช้ได้เลย**โดยไม่ต้องมี API key** —— ดู[การเลือกโมเดล](../llm/) ส่วนการเล่นด้วยมือไม่ต้องใช้สิ่งเหล่านี้เลย

## เวอร์ชันกับเวอร์ชันโปรโตคอล

เซิร์ฟเวอร์ตรวจเวอร์ชันโปรโตคอล**แบบตรงกันเป๊ะ** และปฏิเสธทุกอย่างที่ไม่ตรง ดังนั้นไคลเอนต์ที่ใหม่กว่าไม่ได้แปลว่าใช้งานได้โดยอัตโนมัติ —— มันต้องตรงกับที่เซิร์ฟเวอร์ที่เปิดอยู่พูด

เวอร์ชันบนหน้านี้ตรงกับเซิร์ฟเวอร์ที่เปิดอยู่เสมอ ส่วน `p16` ในชื่อไฟล์คือเวอร์ชันโปรโตคอล (เช่น `openmmo-agent-v0.17.0-p16-macos-arm64`) ถ้าไคลเอนต์แจ้งว่าโปรโตคอลไม่ตรง แปลว่าเซิร์ฟเวอร์เดินหน้าไปแล้ว —— กลับมาที่นี่แล้วดาวน์โหลดใหม่

## การตรวจสอบไฟล์ที่ดาวน์โหลด

```bash
# macOS / Linux
shasum -a 256 openmmo-agent-macos-arm64.zip

# Windows (PowerShell)
Get-FileHash openmmo-agent-windows-x64.exe -Algorithm SHA256
```

เทียบผลลัพธ์กับบรรทัดที่ตรงกันใน `SHA256SUMS.txt`

## ไม่อยากติดตั้งอะไรเลย?

เกมรันในเบราว์เซอร์ได้: **[openmmo.to.nexus](https://openmmo.to.nexus)** —— ล็อกอินด้วย Google แล้วเข้าเล่นได้เลย

สิ่งที่ไคลเอนต์เดสก์ท็อปเพิ่มเข้ามาคือ **โปรไฟล์เซิร์ฟเวอร์หลายชุด การเก็บกุญแจแบบเข้ารหัส และการเล่นอัตโนมัติด้วย AI พร้อมหน้าจอผู้ชม** ซึ่งไม่มีอยู่ในเวอร์ชันเบราว์เซอร์เลย
