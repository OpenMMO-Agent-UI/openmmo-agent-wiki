การเล่นอัตโนมัติต้องใช้ LLM ถ้าคุณเล่นด้วยมือเท่านั้น ข้ามหน้านี้ได้เลย

## การตั้งค่าอยู่ที่ไหน

**การตั้งค่า** มีสี่แท็บ: **LLM**, **เล่นอัตโนมัติ**, **ขั้นสูง**, และ **การกระทำ** ทุกช่องและค่าเริ่มต้นอธิบายไว้ใน[คู่มือแผงควบคุม](../panel/)

## เลือก backend ก่อน

มีสี่ตัว ไม่ใช่แค่ OpenRouter:

| Backend | ต้องมี API key? | เหมาะเมื่อ |
|---|---|---|
| **Codex CLI** | **ไม่ต้อง** —— ใช้ CLI ที่คุณล็อกอินไว้แล้วซ้ำ | คุณใช้ Codex อยู่แล้ว |
| **Claude CLI** | **ไม่ต้อง** —— เหมือนกัน | คุณใช้ Claude Code อยู่แล้ว |
| **OpenRouter** | ต้องมี | คุณต้องการคุ้มค่าที่สุด —— ดูผลวัดด้านล่าง |
| **OpenAI-compatible** | ขึ้นกับ endpoint | โมเดลในเครื่อง (ค่าเริ่มต้นชี้ไปที่ Ollama) หรือโฮสต์เอง |

**ถ้าคุณมี CLI ของ Claude หรือ Codex อยู่แล้ว เลือก backend นั้นก็พอ** —— ไม่ต้องตั้ง API key แยก

ถ้าจะให้ทำงานในเครื่องทั้งหมด เลือก **OpenAI-compatible** แล้วใส่ที่อยู่ Ollama ของคุณใน Base URL ไม่มีค่า API และไม่มีอะไรออกจากเครื่องคุณ —— แต่โมเดลในเครื่องมักช้ากว่าและอาจตามจังหวะเทิร์นของเกมไม่ทัน จึงควรเพิ่มค่า Request timeout ในแท็บขั้นสูง

## ควรใช้โมเดล OpenRouter ตัวไหน

`scripts/bench-models.js` ที่แนบมาให้คะแนนโมเดลที่พิจารณา โดยใช้ prompt ชุดที่ส่งจริง วัดสองเรื่อง: **ติดตามของในกระเป๋าได้ถูกต้องหรือไม่** และ **ยอมปล่อยเป้าหมายที่อยู่นอกระยะหรือไม่** ผลที่วัดได้ (ค่าใช้จ่ายเป็นค่าประมาณสำหรับเล่นต่อเนื่อง 8 ชั่วโมง):

| โมเดล | เวลาตอบกลาง | กระเป๋า | ระยะทาง | ค่าใช้จ่าย / 8 ชม. |
|---|---|---|---|---|
| **`qwen/qwen3.7-flash`** (ค่าเริ่มต้น) | 0.7s | 3/3 | 3/3 | **$0.60** |
| `openai/gpt-oss-20b` | 0.5s | 3/3 | 3/3 | $0.86 |
| `anthropic/claude-haiku-4.5` | 1.5s | 3/3 | 3/3 | $14.34 |
| `mistralai/mistral-nemo` | 0.3s | 0/3 | 0/3 | $0.23 |
| `inclusionai/ling-2.6-flash` | 0.7s | 0/3 | 1/3 | $0.14 |

ค่าเริ่มต้นคือ `qwen/qwen3.7-flash` มันรักษากฎทั้งสองข้อ ตอบในเวลาต่ำกว่าหนึ่งวินาทีมาก และราคาเพียงเศษเสี้ยวของโมเดลระดับแนวหน้า —— นั่นคือสิ่งที่ซื้อจังหวะเทิร์น 8 วินาทีที่เกมต้องการ

ดูสองตัวล่างสุด: **ถูกและล้มเหลวสิ้นเชิง** พวกมันจำของในกระเป๋าผิดและไล่เป้าที่ไปไม่ถึง เวลาเล่นจริงจะเห็นเป็นตัวละครยืนอยู่เฉยๆ โดยไม่ทำอะไรที่เป็นประโยชน์

:::caution[เลี่ยง routing ที่ลงท้ายด้วย `:free`]
routing แบบฟรีวัดเวลารอคิว ไม่ใช่ตัวโมเดล `openai/gpt-oss-20b:free` หมดเวลาที่ 51 วินาที ขณะที่โมเดลเดียวกันบน routing แบบจ่ายเงินตอบใน 0.5 วินาที
:::

## รัน benchmark ด้วยตัวเอง

ถ้าจะวัดโมเดลอื่น:

```bash
OPENROUTER_API_KEY=sk-or-... node scripts/bench-models.js
```

มันคิดราคาจากแคตตาล็อกสด ตัวเลขด้านบนจึงเปลี่ยนไปตามราคาของผู้ให้บริการ
