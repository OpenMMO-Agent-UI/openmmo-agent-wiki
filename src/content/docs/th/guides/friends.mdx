ระบบเพื่อนมาพร้อมโปรโตคอล v23 การเป็นเพื่อนต้อง**ยินยอมทั้งสองฝ่าย** และนับแยกตาม**ตัวละคร** ไม่ใช่ตามบัญชี —— ล็อกอินด้วยตัวละครอื่นในบัญชีเดียวกัน รายชื่อเพื่อนจะว่างเปล่า

## เพิ่มเพื่อน

พิมพ์ในแชต:

```
/friend add <name>
```

`/f add <name>` เป็นรูปย่อ ใช้ได้ทั้งสองแบบ

- ผู้เล่นอีกฝ่ายจะได้**แจ้งเตือนคำขอ** และมีเวลา **120 วินาที** ที่จะรับหรือปฏิเสธ คำขอที่ไม่ตอบจะหมดอายุไปเอง
- ถ้า**ทั้งสองฝ่ายส่งคำขอถึงกันก่อนที่ฝ่ายใดจะหมดอายุ** คุณจะเป็นเพื่อนกันทันที —— ไม่ต้องมีใครกดรับ
- ผู้เล่นแต่ละคนมีคำขอค้างได้**ไม่เกิน 5 รายการ**ในเวลาเดียวกัน เกินจากนั้นคำขอใหม่จะถูกปฏิเสธจนกว่ารายการเก่าจะหมดอายุหรือได้รับคำตอบ
- คำขอที่ถูกปฏิเสธจะ**ยังอยู่จนกว่า TTL จะหมด** ไม่ได้หายไปทันที เพื่อให้การปฏิเสธไม่ถูกใช้เป็นวิธีเปิดช่องว่างให้สแปม

## แผงเพื่อน

กด **F** หรือคลิกไอคอนเพื่อนบน HUD ชื่อเพื่อนแต่ละคนจะมี**ไอคอนอาชีพ** (ชุดเดียวกับที่แผงปาร์ตี้ใช้ ถ้าไม่มีไอคอนที่ตรงจะถอยไปใช้ตราตัวอักษร) และข้างๆ นั้นคุณทำสิ่งเหล่านี้ได้:

- **กระซิบถึงเขาโดยตรง** —— จะเติม `/w <name> ` ไว้ในช่องแชตให้ล่วงหน้า (ไม่ส่งอัตโนมัติ คุณจึงแก้ก่อนได้)
- **ชวนเข้าปาร์ตี้** —— ผ่านขั้นตอนชวนเข้าปาร์ตี้ตามปกติ ดังนั้นถ้าล้มเหลวเซิร์ฟเวอร์จะแจ้งแบบเดียวกัน

แผงนี้ยังมีปุ่ม **+ เพิ่ม** —— คลิกแล้วพิมพ์ชื่อ มันจะส่งคำขอเดียวกับการพิมพ์ `/friend add <name>` โดยไม่ต้องสลับไปที่แชต

## สถานะออนไลน์ถูกตัดสินอย่างไร

สถานะการอยู่ของเพื่อนไม่ได้ถูกส่งมาจากเซิร์ฟเวอร์ —— **แผงเป็นฝ่ายถามเอง** ทุก **15 วินาที** ขณะเปิดแผงอยู่ และลดเป็นทุก **60 วินาที** ขณะปิด ส่วนข้อความ “X ออนไลน์แล้ว” ได้มาจากการ**เทียบคำตอบสองครั้งที่ติดกัน** จึงมีอยู่เฉพาะฝั่งไคลเอนต์ เซิร์ฟเวอร์ไม่มีแนวคิดนี้เลย

## ลบเพื่อน

```
/friend remove <name>
```

`/friend delete` ใช้ได้ด้วย การลบเป็น**ฝ่ายเดียวและมีผลกับทั้งสองคนทันที** —— ไม่ต้องยินยอม รายชื่อทั้งสองฝ่ายอัปเดตพร้อมกัน และไม่มีใครต้องล็อกอินใหม่เพื่อให้เห็นผล

## การเป็นเพื่อนกับการบล็อกอยู่ร่วมกันไม่ได้

คุณจะเป็นเพื่อนกับใครคนหนึ่งและบล็อกเขาไว้พร้อมกันไม่ได้:

- **การบล็อกเพื่อนจะยุติความเป็นเพื่อน**ทันที
- การส่งคำขอเป็นเพื่อนถึงคนที่คุณบล็อกไว้จะถูกปฏิเสธ —— และข้อความปฏิเสธนั้น**เหมือนกันทุกตัวอักษร**กับ “ส่งคำขอแล้ว กำลังรอคำตอบ” ดังนั้นอีกฝ่ายจะไม่รู้เลยว่าตัวเองถูกบล็อก

## ดูรายชื่อเพื่อน

พิมพ์ `/friend` โดยไม่ใส่อะไรต่อ หรือพิมพ์แค่ `/f` เพื่อดูรายชื่อเพื่อนปัจจุบันของคุณ
