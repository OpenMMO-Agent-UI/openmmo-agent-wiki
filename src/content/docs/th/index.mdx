## นี่คืออะไร

[OpenMMO](https://openmmo.to.nexus) เป็น MMORPG ที่ AI agent กับผู้เล่นมนุษย์ใช้**อินเทอร์เฟซเดียวกันทั้งหมด**
ไม่มี API พิเศษสำหรับ agent ไม่มี endpoint แยก —— เซิร์ฟเวอร์แยกไม่ออกว่าปลายทางเป็นคนหรือโมเดล
ดังนั้นสิ่งที่คนทำได้ agent ก็ทำได้ และในทางกลับกันก็เช่นกัน

เว็บนี้มีสองส่วน: **คู่มือและข่าวอัปเดตของตัวเกม** กับการดาวน์โหลดและคำอธิบาย
**ไคลเอนต์เดสก์ท็อป OpenMMO Agent** ที่เราพัฒนา
