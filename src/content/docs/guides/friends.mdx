好友系統在協議 v23 上線。好友需要**雙方同意**才成立,而且記在**角色**身上,
不是整個帳號 —— 換帳號底下另一個角色上線,好友清單是空的。

## 加好友

聊天欄輸入:

```
/friend add <名稱>
```

`/f add <名稱>` 是縮寫,兩種都行。

- 對方會收到一張**邀請提示視窗**,同意或拒絕都要**在 120 秒內**回應,逾時就當沒發生過。
- 如果**雙方在對方的邀請過期前都各自對彼此送出邀請**,不用誰按同意,直接成為好友。
- 每個人**同時最多 5 筆**待處理邀請,超過會被拒絕,得先等舊的過期或被回覆完。
- 對方拒絕的邀請**會保留到 TTL 到期才消失**,不能靠拒絕重新騰出額度來洗版轟炸。

## 好友面板

按 **F**,或點 HUD 上的好友圖示打開面板。面板上每個好友旁邊都能:

- 直接**私訊** —— 會把 `/w <名稱> ` 打進聊天輸入框(不會自動送出,還能改內容再送)。
- **邀請進隊伍** —— 走的是原本的組隊邀請流程,失敗一樣由伺服器回覆原因。

## 線上狀態怎麼來的

好友的上線狀態不是伺服器主動推播,而是**面板自己去問**:開著面板每 **15 秒**問一次,
收起來降到每 **60 秒**一次。「XX 上線了」這種提示是**用前後兩次答案自己比對出來的**,
只存在客戶端本地,伺服器沒有這個概念。

## 移除好友

```
/friend remove <名稱>
```

`/friend delete` 也可以。移除是**單方面、立即雙向生效**的 —— 不用對方同意,
雙方清單同時更新,不用重新登入才看得到。

## 好友與封鎖互斥

一個人不能同時是好友又被封鎖:

- **封鎖已經是好友的人,好友關係會直接解除。**
- 對已封鎖的人送出好友邀請會被擋下 —— 而且擋下時看到的訊息跟
  「邀請已送出、對方還沒回應」**完全相同**,不會讓對方看出自己被封鎖了。

## 查看好友清單

聊天欄打 `/friend`(不加參數)或 `/f` 就能列出目前的好友清單。
