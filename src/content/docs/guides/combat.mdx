## 命中判定

擲一顆 20 面**爆炸骰**:

```
骰出的總和 + 命中加值 >  目標 Guard   →  命中
骰出的總和 + 命中加值 ≤  目標 Guard   →  落空
```

注意是**嚴格大於**。骰出來剛好等於 Guard 是**落空**。

**命中加值**:

- 玩家 = `floor(等級 / 2)` + **STR 調整值** + 武器強化 `+N`
- 怪物 = **等級**(不除 2)—— 比玩家陡,因為玩家 Guard 是靠裝備堆的,不是靠等級。
  `monsters.csv` 裡有指定 `attackBonus` 就用指定值,**場所命中加成**(見下方)
  會疊加在這個值之上。

### 場所命中加成

玩家 Guard 沒有上限,單靠裝備和強化就能一路往上堆;怪物命中加值卻是等級,
最高停在 20——28 分的落差塞不進一顆 20 面骰的窗口。所以難度不是靠怪物本身
拉開,而是**打的地點**:

```
地城:  加成 = max(0, 深度 − 5) × 3
表面:  加成 = max(0, 離城鎮距離 − 300公尺) / 20公尺
```

- 怪物的等級、生命、傷害、經驗值完全不受影響,只有命中加值變高。
- **安全區維持原本難度**:Old Crypt 前 5 層和城鎮周邊 300 公尺加成都是 0。
- 深層地城與遠離城鎮的野外因此明顯變難,強化捲軸(見[強化系統](../enchant/))
  在這些區域從「錦上添花」變成「入場門檻」。

### 爆炸骰是什麼

擲出的 d20 若是 **20,就再擲一顆加上去**;新的一擲又是 20,就繼續加(最多
5 次,總和 120 早就超過任何 Guard)。

```
擲出 13         →  總和 13
擲出 20, 10     →  總和 30
擲出 20, 20, 4  →  總和 44
```

**為什麼要這樣設計。** 如果單純「自然 20 必定命中」,命中率會被釘死在剛好
5%——這只是骰子有 20 面造成的數字,不是平衡判斷的結果:板甲穿好穿滿之後,
狗頭人每二十下還是能咬中你一下。爆炸骰讓**差距越大機率越低,但永遠不會歸
零**:每跨過一個 20 分的門檻,機率就再乘上 1/20。狗頭人(+1)打 Guard 40
的機率是 0.25%,換算下來平均要打 400 下——以牠 1.9 秒的攻速計算,得打
13 分鐘。自然 1 沒有特殊處理。

## 傷害

只有命中才擲傷害。骰子表示法是 `{顆數}d{面數}`:

```
2d6  →  擲兩顆六面骰相加(2–12)
```

玩家近戰傷害會再加上 **STR 調整值**。

### 武器傷害對照

STR 調整值是**加在每一次命中上**的,所以高 STR 對低傷害武器的相對提升更大:
STR 18(+4)拿匕首(1d4,平均 2.5)實際平均是 6.5,等於翻了 2.6 倍。

## Guard 的意義

Guard 是 NetHack 的 AC 反過來 —— **越高越好**。

| Guard | 意義 |
|---|---|
| 0–7 | 幾乎不設防 |
| 8–9 | 防禦薄弱 |
| 10 | 普通 |
| 11–13 | 防禦紮實 |
| 14+ | 重裝以上 |

對照 NetHack:`Guard = 10 − AC`。

## 經驗值

### 打倒怪物拿多少

```
XP = 1 + 等級² + max(Guard - 10, 0) × 2
```

Guard 超過 10 的部分會給獎勵 —— **難打的怪物給得多**。

獸人督軍雖然 XP 最高,但 120 血打起來很久,效率反而不是最好的。

### 升級需要多少

```
XP(n) = 20 × 2^(n-2)      (n ≥ 2)
```

**每一級都是前一級的兩倍**,是純指數曲線,沒有任何緩和。

<FilterTable
  placeholder="輸入等級…"
  columns={[

    { key: 'orcs', label: '約等於幾隻獸人', align: 'right' },

    return {
      level,
      total: xpForLevel(level).toLocaleString(),
      band: level === 1 ? '—' : band.toLocaleString(),

最右欄以獸人(等級 4、Guard 11,每隻 {monsterXp(4, 11)} XP)換算。
可以看到到了兩位數等級之後,靠現有怪物練等會非常慢 ——
目前遊戲的內容量大致對應前 10 級左右。

## 死亡懲罰

死掉**不會掉裝備**,但會扣經驗值:

```
本級區間 = XP(L+1) - XP(L)
扣除量   = max(1, floor(本級區間 × 0.15))
```

也就是**本級進度的 15%**。

### 會不會掉級

扣完之後如果 XP 低於本級的起始值,**降一級**。但有兩個保護:

- **一次死亡最多只掉一級。**
- **等級 1 不會掉級。**

掉級之後,XP 會被拉到下一級區間的 **30% 進度**當作保底 ——
不會讓你卡在剛好差一點升級的位置反覆折磨。

<FilterTable
  placeholder="輸入等級…"
  columns={[
    { key: 'level', label: '等級', align: 'right' },
    { key: 'band', label: '本級區間', align: 'right' },
    { key: 'penalty', label: '死亡扣除', align: 'right' },
    { key: 'orcs', label: '約幾隻獸人補回', align: 'right' },

### 掉級時生命值也會降

為了避免「反覆升級掉級」變成刷生命值的手段,**掉級時扣的生命值分布,
和升級時加的生命值分布完全一樣**:

```
擲 生命骰,保證至少一半,再加 CON 調整值
```

所以長期期望值是 **0** —— 升降級來回不會有任何統計上的好處。
生命值也不會低於等級 1 的初始值。

## 復活

死掉之後送出復活請求,伺服器確認生命為 0 後把你補滿並送回原點 `(0, 0, 0)`。
飽食度會重設為 300(飽足區間的下限),不會讓你餓著復活又馬上衰弱。

### 鳳凰護符:原地復活

背包裡有鳳凰護符時,死亡對話框會多一個「使用鳳凰護符」按鈕。使用後**原地、同一層**復活,
恢復最大生命值的 **70%**,消耗一個護符;死亡時已扣的經驗值懲罰不受影響。跟送回城鎮的
一般復活不同,原地復活**不會重設飽食度**,復活後沒有無敵時間。存活時使用會被拒絕,護符
不會消耗。Rica 販售,5,000 銅,也有 0.2% 世界掉落機率。

## 怪物 AI

怪物的 AI 由客戶端運算,但**攻擊判定一律送伺服器決定**。

| 狀態 | 說明 |
|---|---|
| `idle` | 待機(30% 機率隨機移動) |
| `walk` | 移動中 |
| `run` | 追擊玩家(進入追擊距離) |
| `attack` | 攻擊中(進入攻擊距離) |
| `hit` | 受擊硬直(約 800 毫秒) |
| `dead` | 死亡 |

怪物死亡後 **30 秒**才會從場上移除。各怪物的追擊距離與攻擊間隔見
[怪物圖鑑](../../database/monsters/)。

## 狀態異常

部分怪物攻擊或食物會附加**狀態異常(debuff)**。同一種狀態異常不會疊加,
再次觸發只會刷新持續時間;不同種類可以同時存在,倍率彼此相乘。
