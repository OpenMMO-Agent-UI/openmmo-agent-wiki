釣魚是遊戲的第一個採集職業,也是第一個使用**技能等級**系統的內容。
所有計時、擲骰、判定**全部在伺服器端** —— 客戶端只負責顯示和回應。

魚種、體型、價格等數值表在[釣魚資料](../../database/fishing/);這頁講**怎麼釣**。

## 完整流程

```
拋竿 ─► 拋投中 (1 秒) ─► 等待 (4–12 秒,等級可縮短)
                              │ 咬鉤瞬間就決定了魚種、體型、是否為獎盃
                              ▼
                         咬鉤 (2.5 秒 + 0.5 秒網路寬限)
                         │ 及時揚竿        │ 太慢 / 沒反應
                         ▼                 ▼
                       搏鬥               逃脫
            (張力與體力的連續拉鋸)
                         │ 耗盡體力並收回   │ 線斷 / 脫鉤
                         ▼                 ▼
                       釣獲               逃脫
```

## 準備

買一支 **{itemName('fishing_rod')}**({formatCoins(itemsById.get('fishing_rod').basePrice)}),
**裝備在主手**。Rica 有賣。

:::note[釣竿不會出現在地城寶箱裡]
它是用買的工具,不是戰利品。寶箱只給防具和飾品。
:::

## 拋竿

對著水面點擊。需要滿足:

- 主手裝著釣竿
- 在**地表**(地城裡不能釣)
- 目標在 **8 公尺**以內
- 目標**真的是水** —— 水面高於河床 0.1 公尺以上

**海和河都可以釣。** 河道即使在高地,河面仍高於它自己的河床,所以內陸河一樣成立。
陸地上水面會塌到地形之下,所以點陸地就是走路,不會誤拋。

## 等待與咬鉤

等待時間是 **4–12 秒**均勻分布,每級釣魚等級縮短 **2%**(最短不會低於下限的一半)。

咬鉤時浮標會明顯下沉。你有 **2.5 秒**可以揚竿,另加 **0.5 秒**的網路寬限 ——
這是用**伺服器自己的時鐘**判定的,所以網路慢但確實有按到不會被判失敗,
反過來也不能靠改客戶端拉長視窗。

:::caution[不要提早揚竿]
在咬鉤**之前**揚竿會把魚嚇跑。等浮標沉下去再動。
:::

**揚竿操作**:`SPACE`、任意點擊、或滾輪快撥。

## 搏鬥

揚竿只是開始。搏鬥是伺服器每 **250 毫秒**(每秒 4 次)模擬一次的連續拉鋸。

魚會交替進入兩種狀態:

| 狀態 | 持續 | 說明 |
|---|---|---|
| **奔跑 (Running)** | 2–3.5 秒(越稀有越久) | 用力拉線,張力上升 |
| **休息 (Resting)** | 0.8–2 秒 | 喘息,壓力較小 |

大部分時間魚都在奔跑,所以你多數時候是在承受壓力。

### 三種架式

隨時可以切換:

| 架式 | 操作 | 對張力的影響 |
|---|---|---|
| **收線 (REEL)** | 按住按鈕 / 按住 `SPACE` / 滾輪往下 | **+14/秒** |
| **放線 (GIVE LINE)** | 按住按鈕 / 按住 `S` / 滾輪往上 | **−44/秒** |
| **保持 (HOLD)** | 什麼都不做 | 只有自然衰減 |

`ESC` 直接收線結束(放棄)。

### 張力 —— 會斷線的那條

畫面上的計量條。**到 100 就斷線,魚跑掉。**

| 來源 | 變化量 |
|---|---|
| 揚竿瞬間的起始張力 | **30** |
| 魚奔跑時的拉扯 | **(20 + 2 × 稀有度) / 秒** |
| ↳ 放出去的線越多,最高再 **×1.3** |  |
| ↳ 每級釣魚等級減少 1%,**最多減 30%** |  |
| 收線 | **+14 / 秒** |
| 魚休息時的自然衰減 | **−8 / 秒** |
| 放線 | **−44 / 秒** |

**起始張力 30 是刻意設高的** —— 揚竿之後放著不管,大約一秒就會離開安全區,
再幾秒就斷線。你必須立刻做出反應。

:::tip[放線永遠贏得過拉扯]
放線的 −44/秒 **大於最強的拉扯**(黃金鱘全放線 39/秒)。
所以張力快爆的時候,放線一定壓得下來 —— 代價是線放出去更多,
下一波拉扯的倍率會更高。
:::

**收線 +14 大於休息時的衰減 −8**,所以**不能一直按著收線** ——
這是刻意的設計,逼你在收線和洩壓之間切換。

### 體力 —— 你真正要打掉的東西

**體力不會顯示在計量條上**,但可以從水花的強度判讀 —— 水花越小代表魚越累。

體力池:`38 + 12 × 稀有度`

**只有拉扯會消耗體力**,而且要滿足兩個條件:魚在**奔跑**中,且張力 **≥ 20**。

```
每秒消耗 = 2 + 12 × (張力 / 100)²
```

注意是**平方** —— 這是整個系統的核心:

<FilterTable
  placeholder="輸入張力…"
  columns={[

    const secs = (pool) => `${(pool / drain).toFixed(0)} 秒`;
    return {
      tension: t,
      drain: `${drain.toFixed(2)}`,

      trout: secs(38 + 12 * 3),
      sturgeon: secs(38 + 12 * 5),
    };

/>

**張力 30 打黃金鱘要 32 秒,張力 90 只要 8 秒 —— 差 4 倍。**

而且上表只算「魚在奔跑且張力達標」的**純施壓時間**,實際耗時更長,
因為魚會定期休息。更關鍵的是:**線放鬆的時候,休息中的魚會回復體力** ——
一直保守放線不只是慢,是會倒退的。

### 所以正確打法是

**把張力壓在高檔但不爆掉。** 具體來說:

1. 揚竿後張力從 30 起跳,魚多半立刻開始奔跑。
2. **收線**把張力往上推,推到 80–95 這個區間。
3. 盯著計量條,快到 100 就**放線**洩壓(−44/秒,一秒就能拉回安全)。
4. 洩到大約 60–70 就停止放線,再開始收線推上去。
5. 魚**休息**時是收距離的好時機 —— 這時拉扯小,收線速度也快。

新手最常見的錯誤是**全程放線求穩** —— 張力壓在 20–30,體力幾乎不掉,
魚休息時還會回血,結果是打了三分鐘還在原地。

### 距離與收尾

距離不顯示數字 —— **浮標就是魚的位置**。

| 情況 | 收線速度 |
|---|---|
| 魚在休息 | 1.6 m/s |
| 魚在奔跑 | 0.6 m/s |
| 魚已力竭 | 2.5 m/s |

魚奔跑時會放出 1.1–1.5 m/s 的線,但**不會離開拋竿點 6 公尺以外**。

體力歸零後魚進入**力竭 (Exhausted)** 狀態 —— 這時收線到「線底」附近
(0.3 公尺內)就成功上鉤。

:::caution[還有力氣的魚不能硬拖]
體力沒歸零的魚被拖到距離 1 公尺內會**驚慌爆衝**,重新開始一輪奔跑。
一定要先打光體力再收。
:::

## 什麼會中斷釣魚

會**中斷**:移動、攻擊、斷線、死亡、把釣竿收起來(卸下或換武器到主手)、
主動停止。

**不會**中斷:換帽子、副手拿火把 —— 只要釣竿還在主手就不算分心。

## 釣魚等級

釣獲物給**釣魚經驗**:`10 × 稀有度²`

<FilterTable
  placeholder="搜尋魚種…"
  columns={[
    { key: 'name', label: '釣獲物' },
    { key: 'rarity', label: '稀有度', align: 'center' },
    { key: 'xp', label: '釣魚 XP', align: 'right' },
  ]}
  rows={items
    .filter((i) => i.catchWeight !== null)
    .sort((a, b) => b.rarityTier - a.rarityTier)
    .map((i) => ({
      name: itemName(i.id),
      rarity: i.rarityTier === 0 ? '雜物' : `★${i.rarityTier}`,
      xp: i.rarityTier === 0 ? '0' : 10 * i.rarityTier ** 2,
    }))}
/>

- 上鉤後**逃掉**仍然給 **2 點**安慰經驗。逃脫時**不會告訴你那是什麼魚** ——
  因為安慰經驗如果隨魚種變動,就會洩漏藏起來的擲骰結果。
- 雜物是稀有度 0,所以**完全沒有經驗**。
- **釣魚不給角色經驗值** —— 戰鬥平衡完全不受影響。

### 等級的實際效益

| 效果 | 每級 | 上限 |
|---|---|---|
| 等待時間縮短 | −2% | 下限的一半 |
| 稀有魚的權重提升 | +3% / 每點稀有度 | 無(但乘法,不會顛倒順序) |
| 承受的拉扯降低 | −1% | **−30%** |
| 收線速度提升 | +1% | — |

**等級 10** 解鎖河鮭,**等級 20** 解鎖黃金鱘。沒到等級就完全不會出現。

## AI agent 也能釣

這套機制**刻意設計成人和 agent 都做得到** —— 2.5 秒的反應視窗對 agent 的
網路往返也是合理的,而搏鬥模擬每秒只推進 4 次,所以「反應快」在這裡沒有實質優勢。

桌面客戶端的自動模式會自己揚竿、自己切換架式,LLM 只負責決定「要不要釣、去哪釣」。
