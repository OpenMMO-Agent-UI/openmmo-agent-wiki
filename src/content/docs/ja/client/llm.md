自動プレイには LLM が必要です。手動でしか遊ばないならこのページは飛ばしてください。

## 設定はどこにあるか

**設定**には四つのタブがあります:**LLM**、**自動プレイ**、**詳細**、**アクション**。各項目と既定値は[パネル機能詳細](../panel/)で説明しています。

## まずバックエンドを選ぶ

OpenRouter だけではなく、四つあります:

| バックエンド | API キーは必要? | 向いている場合 |
|---|---|---|
| **Codex CLI** | **不要** —— すでにサインイン済みの CLI を再利用 | すでに Codex を使っている |
| **Claude CLI** | **不要** —— 同じ | すでに Claude Code を使っている |
| **OpenRouter** | 必要 | 費用対性能を最優先 —— 下の実測を参照 |
| **OpenAI-compatible** | エンドポイントによる | ローカルモデル(既定は Ollama を指す)または自前ホスト |

**Claude または Codex の CLI をすでに持っているなら、そのバックエンドを選ぶだけでよい** —— 別途 API キーを用意する必要はありません。

完全にローカルで動かすには **OpenAI-compatible** を選び、Base URL に Ollama のアドレスを入れます。API 費用はかからず、何も端末の外に出ません —— ただしローカルモデルは概して遅く、ゲームのターン間隔に追いつけないことがあるので、詳細の「リクエストタイムアウト」を長くしてください。

## OpenRouter のどのモデルか

同梱の `scripts/bench-models.js` は、実際に出荷されるプロンプトを使って候補モデルを二点で採点します:**バッグの中身を正しく把握し続けられるか**、そして**射程外の相手を諦められるか**。実測結果(費用は連続 8 時間プレイの概算):

| モデル | 応答時間の中央値 | インベントリ | 距離 | 費用 / 8 時間 |
|---|---|---|---|---|
| **`qwen/qwen3.7-flash`** (既定) | 0.7s | 3/3 | 3/3 | **$0.60** |
| `openai/gpt-oss-20b` | 0.5s | 3/3 | 3/3 | $0.86 |
| `anthropic/claude-haiku-4.5` | 1.5s | 3/3 | 3/3 | $14.34 |
| `mistralai/mistral-nemo` | 0.3s | 0/3 | 0/3 | $0.23 |
| `inclusionai/ling-2.6-flash` | 0.7s | 0/3 | 1/3 | $0.14 |

既定は `qwen/qwen3.7-flash` です。二つのルールをどちらも守り、1 秒を大きく下回って応答し、フロンティアモデルのごく一部の費用で済みます —— それがゲームの求める 8 秒のターン間隔を買うものです。

下の二つを見てください:**安くて、まったく機能していません。** バッグの中身を取り違え、届かない相手を追いかけます。遊んでいて何が起きるかというと、キャラクターが立ち止まって無意味な動きをします。

:::caution[`:free` 付きのルーティングは避ける]
無料ルーティングが測っているのは待ち時間で、モデルの性能ではありません。`openai/gpt-oss-20b:free` は 51 秒でタイムアウトし、同じモデルが有料ルーティングでは 0.5 秒で答えました。
:::

## ベンチマークを自分で走らせる

他のモデルを測るには:

```bash
OPENROUTER_API_KEY=sk-or-... node scripts/bench-models.js
```

実行時に公開カタログの価格を参照するので、上の数字は提供元の価格変動に合わせて動きます。
