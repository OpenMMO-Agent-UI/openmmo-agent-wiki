title: 'フレンド機能'
description: '`/friend` の申請と同意の仕組み、ブロックとフレンドが両立しない理由、フレンドパネル、そしてオンライン状態の判定方法。'
---

フレンド機能はプロトコル v23 で実装されました。フレンドには**双方の同意**が必要で、管理単位は**キャラクター**ごと、アカウントごとではありません —— 同じアカウントの別キャラクターでログインすると、フレンドリストは空です。

## フレンドを追加する

チャットに次を入力します:

```
/friend add <name>
```

`/f add <name>` は短縮形です。どちらでも動きます。

- 相手には**申請のトーストが表示され、承諾または辞退に 120 秒**の猶予があります。答えないまま放置された申請は、そのまま期限切れになります。
- **どちらの申請も期限切れになる前に双方が互いに申請を送った場合**、その時点でフレンドになります —— 誰も承諾を押す必要はありません。
- 保留中の申請は 1 人につき**最大 5 件**までです。それを超えると、古いものが期限切れになるか回答されるまで新しい申請は拒否されます。
- 辞退された申請も**すぐには消えず、TTL が切れるまで残ります**。辞退をスパム用の枠空けに使えないようにするためです。

## フレンドパネル

**F** を押すか、HUD のフレンドアイコンをクリックします。各フレンドの名前には**職業アイコン**(パーティーパネルと同じ一式。対応するアイコンがなければ文字バッジに戻ります)が付き、その隣から次ができます:

- **直接ささやく** —— チャット入力欄に `/w <name> ` を先に入れておきます(自動送信はしないので、先に編集できます)。
- **パーティーに招待する** —— 通常のパーティー招待の流れを通るので、失敗したときの通知もサーバーから同じように返ります。

パネルには **+ 追加** ボタンもあります。クリックして名前を入力すると、チャットに切り替えずに `/friend add <name>` と同じ申請を送ります。

## オンライン状態はどう判定されるか

フレンドの在席状況はサーバーからプッシュされません —— **パネルがポーリングします**。パネルが開いている間は **15 秒**ごと、閉じている間は **60 秒**ごとに下がります。「X がオンラインになりました」という通知は**連続する応答の差分**から導かれるので、クライアント側にしか存在しません。サーバーにその概念はありません。

## フレンドを削除する

```
/friend remove <name>
```

`/friend delete` も使えます。削除は**一方的で、双方に即座に反映されます** —— 同意は不要で、両方のリストが同時に更新され、どちらも再ログインせずに反映を見られます。

## フレンドとブロックは両立しない

誰かのフレンドでありながら、同時にその相手をブロックしておくことはできません:

- **フレンドをブロックすると、その時点でフレンド関係は終了します。**
- 自分がブロックした相手にフレンド申請を送ると拒否されます —— そして拒否のメッセージは「申請を送信しました。返事を待っています」と**一字一句同じ**なので、相手は自分がブロックされていることを知るすべがありません。

## フレンドを一覧する

引数なしで `/friend`、あるいは単に `/f` と入力すると、現在のフレンドが一覧表示されます。
