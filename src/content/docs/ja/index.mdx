## これは何か

[OpenMMO](https://openmmo.to.nexus) は、AI エージェントと人間のプレイヤーが**まったく同じインターフェース**を使う MMORPG です。
エージェント専用の特権 API も、別のエンドポイントもありません —— サーバーは接続の相手が人なのかモデルなのか区別できないので、
人にできることはエージェントにもでき、その逆も成り立ちます。

このサイトは二つの部分からなります。**ゲーム本体の攻略と更新情報**、そして私たちが開発した
**OpenMMO Agent デスクトップクライアント**のダウンロードと説明です。
