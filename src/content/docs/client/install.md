## 繞過未簽章警告

安裝檔沒有經過簽章,三個平台都會擋一次。

### macOS

Gatekeeper 會拒絕直接雙擊開啟。解壓縮後選其中一種:

- **右鍵 → 開啟**,在跳出的對話框再按一次「開啟」。只需要做一次。
- 或者用終端機清掉隔離屬性:

  ```bash
  xattr -cr "OpenMMO Agent.app"
  ```

### Windows

SmartScreen 會顯示「已保護您的電腦」。點**其他資訊** → **仍要執行**。

### Linux

AppImage 需要自己加上執行權限:

```bash
chmod +x openmmo-agent-linux-x64.AppImage
./openmmo-agent-linux-x64.AppImage
```

## 首次啟動流程

四個畫面,依序走完就進遊戲了。**沒有獨立的「開始遊玩」按鈕** ——
選好角色就直接進場。

### 1. Server —— 選擇連線設定檔

內建的 `openmmo.to.nexus` 設定檔是固定的,一般玩家直接用這個。

一個設定檔綁定三件事:伺服器網址、地形資源來源、Google client id/secret。
這三者必須成套,因為每台伺服器只接受自己允許清單內的 client id 所簽發的登入憑證。
如果你要連自架伺服器,可以新增、編輯、複製、刪除自訂設定檔,並在使用前先測試連線。

### 2. Login —— Google 裝置流程登入

點下按鈕後會顯示一組代碼,在瀏覽器輸入即可。已登入過的話會直接跳到下一步。

### 3. Character —— 選擇或建立角色

兩個頁籤:

- **選擇角色** —— 每個帳號最多 3 隻(伺服器強制)。點選即進入遊戲,也可以刪除。
- **建立角色** —— 填名稱、職業、性別。角色數達上限時這個頁籤會隱藏。

### 4. Game —— 進入遊戲

進場時會自動判斷模式:**若已設定並通過驗證的 LLM 後端,走自動模式;
否則走手動模式**。自動模式啟動失敗時也會退回手動。之後可以隨時在標題列切換。

## 兩種遊玩模式

伺服器對每個角色只允許**一個**控制連線,所以兩種模式的實作方式不同。

**手動模式**是直接連線 —— 內嵌的 OpenMMO 網頁客戶端用你自己的 Google 登入,
直接跟伺服器對話,跟開瀏覽器玩完全一樣。沒有中繼、不啟動 agent。

**自動模式**會啟動 `agent-client`,而它需要獨佔那唯一的連線 ——
所以「在旁邊觀看」不能靠再登入一個連線。客戶端改為在本機開一個中繼:

```
agent-client <--ws--> proxy (127.0.0.1) <--wss--> openmmo.to.nexus
                        |
                        +--> 觀戰視角 (/mirror)
```

伺服器完全不知道 agent 後面還有東西。中繼位在中間,可以把每一則伺服器訊息
複製一份給唯讀的觀戰視角。**中繼只綁定 `127.0.0.1`,沒有任何資料離開你的電腦。**

## 遊戲畫面

標題列顯示連線狀態、生命與狀態值、觀戰記憶體用量、3D 視角重新載入按鈕、
手動/AI 模式切換,以及更換角色或伺服器的按鈕。
執行中改了設定的話,會多出一個 **Apply & restart** 按鈕。

左側欄可以拉出五個抽屜:

| 抽屜 | 內容 |
|---|---|
| Equipment | 目前穿戴的裝備,逐格顯示 |
| Bag | 背包內容 |
| Personality | 這隻角色專屬的提示詞,疊在共用規則之上。執行中儲存會重啟 agent |
| Thoughts | 每一次送出的提示與回覆,附時間 |
| Log | agent 程序本身的輸出 |

遊戲畫面下方的 **Dispatch** 是唯一能對執行中的 agent 說話的管道:
輸入一句指示,它會成為角色下一個回合的參考。這是**盡力而為**,不保證照做。

## 你的金鑰存在哪裡

API key 與連線設定檔的密鑰都用作業系統的鑰匙圈加密
(Electron `safeStorage`,失敗時退回 AES-GCM),再以環境變數交給 agent ——
**不會寫進 `config.toml`**。所以把設定檔貼進 bug 回報不會外洩任何憑證。

## 疑難排解

**顯示協議版本不符** —— 伺服器已更新。回[下載頁](../download/)取得新版本。

**改了設定但沒有生效** —— agent 只在啟動時讀一次設定。按標題列的
**Apply & restart**。

**從 VS Code 的終端機啟動後卡住不開** —— VS Code 自己是 Electron 應用,
會外洩 `ELECTRON_RUN_AS_NODE=1`,導致客戶端以純 Node 模式啟動。改用:

```bash
env -u ELECTRON_RUN_AS_NODE npm start
```

**觀戰視角有東西沒動或沒出現** —— 自動模式的觀戰視角從一份快照開始,
agent 知道但當下沒有追蹤的東西,會在重新進入視野時才出現。
