## 標題列

| 元件 | 作用 |
|---|---|
| 連線狀態 | 目前是否連上伺服器 |
| 生命與狀態 | 角色的即時數值 |
| 觀戰記憶體用量 | 3D 觀戰畫面吃掉多少記憶體 |
| 重新載入 | 重載 3D 觀戰畫面(畫面卡住或錯亂時用) |
| **暫停 / 繼續(⏸ / ▶)** | 暫停執行中的 agent。暫停期間不會呼叫 LLM,也就不會計費 —— 想中途接手或省錢時用 |
| **Apply & restart** | **只在 agent 執行中改了設定時才出現。** agent 只在啟動時讀一次設定,所以改完必須按這個 |
| **自動 / 手動切換** | 兩種模式即時互換。自動模式下實際操作角色的是**自動打工人**(見下) |
| 更換角色 / 更換伺服器 | 回到前面的畫面 |

## 左側三個抽屜

左緣那排圖示沒有文字,滑過或用鍵盤聚焦才會顯示名稱。

### 角色(Character)

三個分頁:

- **數值(Stats)** —— 等級、屬性、已學技能與稱號。稱號可以在這裡切換。
- **裝備(Equipment)** —— 身上穿戴的每一格,空格也會列出來。
- **背包(Bag)** —— 攜帶的物品,以及賣出/丟棄的標記(見下一節)。

:::note[為什麼裝備要從中繼看]
agent 自己的面板 API **只回報背包、不回報身上的裝備**。
所以裝備分頁的資料是從中繼看到的庫存封包還原出來的 ——
這是桌面客戶端加值的東西之一,直接跑 `agent-client` 看不到。
:::

#### 背包的賣出與丟棄標記

每一列有兩個勾選框,欄位名稱寫在列表上方一次,不在每列重複:

- **賣出(Sell)** —— 允許打工人把它賣給商人
- **丟棄(Drop)** —— 允許打工人把它丟在地上

勾選只是暫存,按 **Apply labels** 才寫入。幾件要知道的事:

- 標記是**以物品為單位**,不分附魔等級 —— agent 的賣出與丟棄動作沒有附魔欄位。
  所以同一件東西帶了 +0 和 +2 會合成一列,等級寫在名稱裡(`鐵劍 (+0, +2)`)。
- 上方的**顯示遊戲中所有物品**切換,會把清單換成遊戲裡每一樣可攜帶的物品,
  所以**不必先持有就能先標記** —— 這對地城征服者特別有用:你想預先決定不要撿的東西,
  正是你還沒撿到的東西。預設只列背包裡有的。
- **沒有標記就不處分。** 這是防止打工人賣掉你辛苦打到的裝備的閘門。
- 有兩類東西標了也不會動:**隨身補給**(藥水、回城卷軸、食物、釣竿、韁繩)
  和**地城鑰匙**。鑰匙被丟掉會讓地城跑進無盡循環 —— 丟掉、回去刷、再丟掉。
- 同時勾選賣出與丟棄時,**會賣掉而不是丟掉**:賣有錢拿。
- 丟棄標記在**撿之前**就生效 —— 勾了的東西,打工人根本不會撿起來,
  連重量都不會揹。地城裡已經在身上的,一進新的一層就會丟掉。

補給的實際行為有幾個不會寫在欄位上的規則:

- 選了商人沒賣的東西,會退而買那家店同類的其他貨 —— 麵包是 Wick 的,不是 Rica 的。
- **商人會睡覺。** 入夜後店主走回家躺上床,伺服器會拒絕所有交易。
  打工人不會把睡著的店主當成「我來找的那個商人」,
  會走完城裡各站找清醒的;都沒有就等五分鐘再回來,並在紀錄裡說是誰睡了。
- 地城征服者**沒有藥水就不會下坑**:等買到再走。
  但如果錢不夠買一瓶,它還是會下去 —— 地城征服者的錢來自寶箱,死等會變死結。

### 動態(Activity)

兩個分頁:

- **Thoughts** —— 打工人每一回合的決定與進度說明,附時間。
  有**篩選器**、**Follow**(自動捲到最新)和 **Clear**。
  地城征服者在這裡會說它在哪一層、缺哪把鑰匙、為什麼停下來。
- **Log** —— agent 程序本身的 stdout / stderr。

想知道它為什麼做某個決定,看 Thoughts;想知道它為什麼壞掉,看 Log。
**丟棄也會寫在這裡**,逐項列出丟了什麼 —— 東西丟掉不會回來,
所以這是唯一能回頭查的紀錄。

### About — 關於

版本、檢查更新、清除資源快取、隱私說明(只回報 app 啟動與遊玩模式,
經 Aptabase,**不含帳號、角色或伺服器**),以及 **Advanced** 區塊裡的
**Watch port**(本機觀戰面板的連接埠,預設 8808)和 **Log level**
(回報問題前先開 debug)。

## 連線設定檔

在 **Server** 畫面管理。內建的 `openmmo.to.nexus` 是固定的,不能改;
自訂的可以新增、編輯、複製、刪除,而且**使用前可以先測試連線**。

一個設定檔包含:

| 欄位 | 說明 |
|---|---|
| Profile name | 設定檔名稱 |
| Game server | 遊戲伺服器的 WebSocket 位址 |
| Terrain origin | 地形資源的來源位址 |
| Google client ID | 該伺服器接受的 OAuth client |
| Google client secret | 對應的密鑰,加密保存 |

**這五項必須成套** —— 每台伺服器只接受自己允許清單內的 client ID 所簽發的登入憑證,
所以 client ID 不能跨伺服器共用。

## 你的機密資料放在哪

API key 與連線設定檔的密鑰都用作業系統的鑰匙圈加密
(Electron `safeStorage`,失敗時退回 AES-GCM),再以**環境變數**交給 agent。

**不會寫進 `agent-client` 的設定檔** —— 所以把設定檔貼進 bug 回報不會外洩憑證。
設定檔本身每次啟動都會從面板重新產生;如果你原本有手寫的設定檔,
會被匯入一次並在旁邊留下備份。
