## 標題列

| 元件 | 作用 |
|---|---|
| 連線狀態 | 目前是否連上伺服器 |
| 生命與狀態 | 角色的即時數值 |
| 觀戰記憶體用量 | 3D 觀戰畫面吃掉多少記憶體 |
| 重新載入 | 重載 3D 觀戰畫面(畫面卡住或錯亂時用) |
| **暫停 / 繼續(⏸ / ▶)** | 暫停執行中的 agent。暫停期間不會呼叫 LLM,也就不會計費 —— 想中途接手或省錢時用 |
| **Apply & restart** | **只在 agent 執行中改了設定時才出現。** agent 只在啟動時讀一次設定,所以改完必須按這個 |
| 手動 / AI 切換 | 兩種模式即時互換 |
| 更換角色 / 更換伺服器 | 回到前面的畫面 |

## 左側六個抽屜

### Equipment — 裝備

顯示目前穿戴的裝備,逐格列出。

:::note[為什麼裝備要從中繼看]
agent 自己的面板 API **只回報背包、不回報身上的裝備**。
所以這個抽屜的資料是從中繼看到的庫存封包還原出來的 ——
這是桌面客戶端加值的東西之一,直接跑 `agent-client` 看不到。
:::

### Bag — 背包

顯示攜帶的物品。除了看,還可以**標記 agent 能不能處分某樣東西**:

- **S(Sellable)** — 允許 agent 賣掉
- **D(Dropable)** — 允許 agent 丟掉

勾選後按 **Apply labels** 才會送出(是暫存的,不會勾一個送一次)。

這是防止 agent 亂賣東西的閘門 —— 你辛苦打到的裝備,不標記它就不會處分。

### Personality & Memory — 個性與記憶

兩塊內容:

- **Personality** —— 這隻角色專屬的提示詞,疊在共用規則之上。可以編輯。
  **在 agent 執行中儲存會重啟 agent。**
- **Memory** —— 這隻角色記得什麼,**由 agent 自己寫入,唯讀**。

Personality 是你塑造角色行為的地方(「你是個謹慎的獵人,血量低於一半就撤退」),
Memory 則是它自己累積下來的東西。

### Coordinates — 座標

存放地點書籤。可以用 **Use current position** 直接記下目前位置,再命名加入。

配合 Dispatch 使用:記下釣點、地城入口、商店位置,之後叫 agent 去那裡。

### Dispatch Presets — 派遣預設

把常用的指令存成有名字的預設,之後一鍵送出,不用每次重打。

每個預設有**名稱**和**要送出的提示詞**。存好之後會變成 Dispatch 輸入框旁的按鈕。

### Activity — 活動

兩個分頁:

- **Thoughts** —— 每一次送出的提示與收到的回覆,附時間。
  有**篩選器**、**Follow**(自動捲到最新)和 **Clear**。
- **Log** —— agent 程序本身的 stdout / stderr。

想知道 agent 為什麼做某個決定,看 Thoughts;想知道它為什麼壞掉,看 Log。

## Dispatch

遊戲畫面下方那一條,是**唯一能對執行中的 agent 說話的管道**。

輸入一句指示,它會成為角色下一個回合的參考 —— **盡力而為,不保證照做**。
它是「悄悄話」不是「指令」:你在建議,決定權還是在模型手上。

## 連線設定檔

在 **Server** 畫面管理。內建的 `openmmo.to.nexus` 是固定的,不能改;
自訂的可以新增、編輯、複製、刪除,而且**使用前可以先測試連線**。

一個設定檔包含:

| 欄位 | 說明 |
|---|---|
| Profile name | 設定檔名稱 |
| Game server | 遊戲伺服器的 WebSocket 位址 |
| Terrain origin | 地形資源的來源位址 |
| Google client ID | 該伺服器接受的 OAuth client |
| Google client secret | 對應的密鑰,加密保存 |

**這五項必須成套** —— 每台伺服器只接受自己允許清單內的 client ID 所簽發的登入憑證,
所以 client ID 不能跨伺服器共用。

## 你的機密資料放在哪

API key 與連線設定檔的密鑰都用作業系統的鑰匙圈加密
(Electron `safeStorage`,失敗時退回 AES-GCM),再以**環境變數**交給 agent。

**不會寫進 `agent-client` 的設定檔** —— 所以把設定檔貼進 bug 回報不會外洩憑證。
設定檔本身每次啟動都會從面板重新產生;如果你原本有手寫的設定檔,
會被匯入一次並在旁邊留下備份。
