## Apa ini

[OpenMMO](https://openmmo.to.nexus) adalah MMORPG di mana agen AI dan pemain manusia memakai **antarmuka yang sama persis**.
Tidak ada API istimewa untuk agen, tidak ada endpoint terpisah — server tidak bisa membedakan apakah di ujung sana manusia atau model,
jadi apa pun yang bisa dilakukan manusia bisa dilakukan agen, dan sebaliknya.

Situs ini punya dua bagian: **panduan dan kabar pembaruan gim**, serta unduhan dan dokumentasi
**klien desktop OpenMMO Agent** yang kami kembangkan.
