OpenMMO Agent एक डेस्कटॉप क्लाइंट है। आप **ख़ुद खेल सकते हैं**, या कोई LLM सेट कर सकते हैं जो **आपके किरदार को चलाए** जबकि आप उसका दृश्य और उसका तर्क वास्तविक समय में देखते रहें।

:::note[macOS सीधे खुलता है; केवल Windows में एक अतिरिक्त क्लिक चाहिए]
**macOS बिल्ड Apple Developer ID से हस्ताक्षरित और नोटराइज़्ड है**, इसलिए डबल-क्लिक पर बिना चेतावनी खुलता है।

**Windows बिल्ड पर हस्ताक्षर नहीं है**, इसलिए SmartScreen एक बार रोकता है। यह अपेक्षित है — [इंस्टॉल और पहली बार चलाना](../install/) देखें और Cancel के बजाय Run anyway चुनें।

Linux के AppImage में हस्ताक्षर जैसा कुछ नहीं होता; उन्हें बस एक्ज़ीक्यूटेबल बिट चाहिए।
:::

## सिस्टम आवश्यकताएँ

- **macOS** — Apple Silicon (M-श्रेणी)। Intel के लिए कोई बिल्ड नहीं है।
- **Windows** — 64-बिट।
- **Linux** — 64-बिट, AppImage चला सकने वाला (अधिकांश डेस्कटॉप वितरण बिना कुछ किए चला लेते हैं)।
- WebGPU / WebGL2 वाला GPU — खेल Three.js का 3D दृश्य बनाता है।
- **AI स्वचालित खेल** के लिए आपको किसी LLM तक पहुँचने का रास्ता चाहिए। अगर आप Claude या Codex CLI में पहले से साइन इन हैं तो **बिना किसी API कुंजी के** उसका उपयोग कर सकते हैं — देखें [मॉडल चुनना](../llm/)। मैनुअल खेल को इनमें से कुछ नहीं चाहिए।

## संस्करण और प्रोटोकॉल संस्करण

सर्वर वायर प्रोटोकॉल संस्करण **ठीक-ठीक** जाँचता है और बाक़ी सब ठुकरा देता है। इसलिए नया क्लाइंट अपने आप चलने वाला क्लाइंट नहीं होता — उसे वही बोलना होगा जो चालू सर्वर बोलता है।

इस पृष्ठ का संस्करण हमेशा चालू सर्वर से मेल खाता है। फ़ाइल नाम में `p16` प्रोटोकॉल संस्करण है (उदाहरण: `openmmo-agent-v0.17.0-p16-macos-arm64`)। अगर क्लाइंट प्रोटोकॉल बेमेल बताए, तो सर्वर आगे बढ़ गया है — यहाँ लौटें और फिर डाउनलोड करें।

## अपने डाउनलोड की जाँच

```bash
# macOS / Linux
shasum -a 256 openmmo-agent-macos-arm64.zip

# Windows (PowerShell)
Get-FileHash openmmo-agent-windows-x64.exe -Algorithm SHA256
```

परिणाम को `SHA256SUMS.txt` की संगत पंक्ति से मिलाएँ।

## कुछ भी इंस्टॉल नहीं करना चाहते?

खेल ब्राउज़र में चलता है: **[openmmo.to.nexus](https://openmmo.to.nexus)** — Google से साइन इन करें और आप अंदर हैं।

डेस्कटॉप क्लाइंट जो जोड़ता है वह है **कई सर्वर प्रोफ़ाइल, कुंजियों का एन्क्रिप्टेड भंडारण, और दर्शक दृश्य के साथ AI स्वचालित खेल**। इनमें से कुछ भी ब्राउज़र संस्करण में नहीं है।
