স্বয়ংক্রিয় খেলার জন্য একটি LLM দরকার। যদি আপনি কেবল নিজে খেলেন, এই পৃষ্ঠাটি এড়িয়ে যান।

## সেটিংস কোথায়

**সেটিংস**-এ চারটি ট্যাব: **LLM**, **স্বয়ংক্রিয় খেলা**, **উন্নত**, এবং **ক্রিয়া**। প্রতিটি ঘর ও তার পূর্বনির্ধারিত মান [প্যানেল রেফারেন্সে](../panel/) বর্ণনা করা আছে।

## আগে একটি backend বাছুন

চারটি আছে, কেবল OpenRouter নয়:

| Backend | API কী লাগবে? | ভালো যদি |
|---|---|---|
| **Codex CLI** | **না** — আপনি যে CLI-তে ইতিমধ্যে সাইন ইন করা, সেটিই ব্যবহার করে | আপনি আগে থেকেই Codex ব্যবহার করেন |
| **Claude CLI** | **না** — একই | আপনি আগে থেকেই Claude Code ব্যবহার করেন |
| **OpenRouter** | হ্যাঁ | আপনি সেরা খরচ/কার্যক্ষমতা চান — নিচের মাপ দেখুন |
| **OpenAI-compatible** | endpoint-এর উপর নির্ভর করে | স্থানীয় মডেল (পূর্বনির্ধারিত Ollama-র দিকে নির্দেশ করে) বা নিজে হোস্ট করা |

**আপনার কাছে যদি আগে থেকেই Claude বা Codex CLI থাকে, তবে ওই backend-টাই বাছুন** — আলাদা কোনো API কী সাজানোর দরকার নেই।

সম্পূর্ণ স্থানীয়ভাবে চালাতে **OpenAI-compatible** বাছুন এবং Base URL-এ আপনার Ollama ঠিকানা দিন। কোনো API খরচ নেই, কিছুই আপনার মেশিন ছেড়ে যায় না — তবে স্থানীয় মডেল সাধারণত ধীর এবং খেলার টার্নের ছন্দ ধরে রাখতে না-ও পারে, তাই উন্নত ট্যাবে Request timeout বাড়িয়ে দিন।

## OpenRouter-এর কোন মডেল

সঙ্গে দেওয়া `scripts/bench-models.js` প্রার্থী মডেলগুলোকে সেই prompt দিয়েই যাচাই করে যা সত্যিই পাঠানো হয়, দুটি বিষয়ে: **তারা থলিতে কী আছে তার হিসাব ঠিক রাখে কি না**, এবং **নাগালের বাইরের লক্ষ্য ছেড়ে দেয় কি না**। মাপা ফলাফল (খরচ টানা ৮ ঘণ্টা খেলার আনুমানিক হিসাব):

| মডেল | মধ্যমা সাড়া | থলি | দূরত্ব | খরচ / ৮ ঘণ্টা |
|---|---|---|---|---|
| **`qwen/qwen3.7-flash`** (পূর্বনির্ধারিত) | 0.7s | 3/3 | 3/3 | **$0.60** |
| `openai/gpt-oss-20b` | 0.5s | 3/3 | 3/3 | $0.86 |
| `anthropic/claude-haiku-4.5` | 1.5s | 3/3 | 3/3 | $14.34 |
| `mistralai/mistral-nemo` | 0.3s | 0/3 | 0/3 | $0.23 |
| `inclusionai/ling-2.6-flash` | 0.7s | 0/3 | 1/3 | $0.14 |

পূর্বনির্ধারিত হলো `qwen/qwen3.7-flash`: এটি দুটি নিয়মই রাখে, এক সেকেন্ডের অনেক কমে উত্তর দেয়, আর কোনো অগ্রণী মডেলের তুলনায় সামান্য খরচে চলে — আর ঠিক এটাই খেলার চাওয়া ৮ সেকেন্ডের টার্ন-ছন্দ কিনে দেয়।

নিচের দুটি দেখুন: **সস্তা এবং সম্পূর্ণ ব্যর্থ।** তারা থলির হিসাব ভুল মনে রাখে আর এমন লক্ষ্যের পিছনে ছোটে যেখানে পৌঁছাতে পারে না। খেলায় এটি দেখা যায় এভাবে — চরিত্র দাঁড়িয়ে আছে, কাজের কিছুই করছে না।

:::caution[`:free` প্রত্যয়যুক্ত routing এড়ান]
বিনামূল্যের routing সারিতে অপেক্ষার সময় মাপে, মডেলকে নয়। `openai/gpt-oss-20b:free` ৫১ সেকেন্ডে টাইমআউট হয়েছে, যেখানে একই মডেল সশুল্ক routing-এ ০.৫ সেকেন্ডে উত্তর দিয়েছে।
:::

## benchmark নিজে চালানো

অন্য মডেল মাপতে:

```bash
OPENROUTER_API_KEY=sk-or-... node scripts/bench-models.js
```

এটি সরাসরি ক্যাটালগের বিপরীতে দাম হিসাব করে, তাই উপরের সংখ্যাগুলো সরবরাহকারীর দামের সঙ্গে বদলায়।
