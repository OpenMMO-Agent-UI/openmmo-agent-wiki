## প্রথমবার খোলা

### macOS — এমনিই খোলে

**macOS বিল্ডটি Apple Developer ID দিয়ে সই করা, Apple কর্তৃক নোটারাইজ করা, এবং টিকিটটি অ্যাপের সঙ্গে গাঁথা আছে।** আনজিপ করুন, ডাবল-ক্লিক করুন, Gatekeeper-এর কোনো সতর্কবার্তা ছাড়াই চলবে।

আপনার রাইট-ক্লিক → Open দরকার নেই, `xattr -cr`-ও দরকার নেই — সই না করা অ্যাপের জন্য ইন্টারনেটে যে পরামর্শ পাবেন, তা এই বিল্ডে খাটে না।

### Windows — একটি বাড়তি ক্লিক

**Windows বিল্ডটি সই করা নয়**, তাই SmartScreen দেখায় “Windows protected your PC”। **More info** → **Run anyway** চাপুন।

কোড-সাইনিং সার্টিফিকেটে প্রতি বছর খরচ হয় এবং এখন কেবল একটিই আছে, macOS-এর জন্য। প্রকল্পটি আপনার কাজে লাগলে, [সমর্থন করা](https://ko-fi.com/dakywang) একটি Windows সার্টিফিকেট নাগালে আনতে সাহায্য করে।

### Linux — এক্সিকিউটেবল বিট দিন

AppImage-এ সই বলার মতো কিছু নেই; কেবল চালানোর যোগ্য হলেই হয়:

```bash
chmod +x openmmo-agent-*linux-x64.AppImage
./openmmo-agent-*linux-x64.AppImage
```

## প্রথম চালু

ক্রমে চারটি পর্দা, আর আপনি খেলার ভেতরে। **আলাদা “খেলুন” ধাপ নেই** — চরিত্র বেছে নেওয়াই সঙ্গে সঙ্গে খেলায় প্রবেশ।

### ১. সার্ভার — একটি সংযোগ প্রোফাইল বাছুন

সঙ্গে দেওয়া `openmmo.to.nexus` প্রোফাইলটি স্থির, আর অধিকাংশ খেলোয়াড় এটিই চান।

একটি প্রোফাইল তিনটি জিনিস একসঙ্গে বাঁধে: সার্ভারের URL, ভূদৃশ্য সম্পদের উৎস, এবং একটি Google ক্লায়েন্ট ID ও secret। এগুলোকে একসঙ্গেই চলতে হয়, কারণ সার্ভার কেবল তার নিজের অনুমোদিত তালিকার ক্লায়েন্ট ID থেকে ইস্যু করা সাইন-ইন টোকেনই নেয়। নিজের সার্ভার চালালে আপনি প্রোফাইল তৈরি, সম্পাদনা, নকল ও মুছতে পারেন, এবং ব্যবহারের আগে সংযোগ পরীক্ষা করতে পারেন।

### ২. লগইন — Google-এর ডিভাইস ফ্লো

বোতাম চাপলে একটি কোড আসবে; সেটি আপনার ব্রাউজারে দিন। ক্যাশে রাখা পরিচয়পত্র থাকলে সোজা পরের ধাপে চলে যায়।

### ৩. চরিত্র — বাছুন বা তৈরি করুন

দুটি ট্যাব:

- **আপনার চরিত্র বাছুন** — প্রতি অ্যাকাউন্টে সর্বোচ্চ ৩টি (সার্ভার বাধ্য করে)। খেলায় ঢুকতে ক্লিক করুন, বা মুছুন।
- **নতুন চরিত্র তৈরি করুন** — নাম, শ্রেণি, লিঙ্গ। সীমায় পৌঁছালে লুকিয়ে যায়।

### ৪. খেলা

প্রবেশের সময় মোড আপনার হয়ে ঠিক হয়ে যায়: **কোনো LLM backend সাজানো থাকলে ও যাচাই উতরোলে স্বয়ংক্রিয়, নইলে হাতে চালানো**। স্বয়ংক্রিয় চালু না হলে হাতে চালানোয় নেমে আসে। উপরের বার থেকে যখন খুশি বদলাতে পারেন।

## দুটি খেলার ধরন

সার্ভার প্রতি চরিত্রে ঠিক একটি নিয়ন্ত্রণ সেশন অনুমোদন করে, তাই দুটি ধরন সেখানে ভিন্ন পথে পৌঁছায়।

**হাতে খেলা** সরাসরি সংযোগ — ভেতরে বসানো OpenMMO ওয়েব ক্লায়েন্ট আপনার নিজের Google অ্যাকাউন্টে সাইন ইন করে সরাসরি সার্ভারের সঙ্গে কথা বলে, একেবারে ব্রাউজারে খেলার মতোই। কোনো রিলে নেই, `agent-client` নেই।

**স্বয়ংক্রিয় খেলা** `agent-client` চালু করে, যার ওই একটিমাত্র সেশন নিজের জন্য দরকার — তাই তাকে দেখা মানে তার পাশে লগইন করা হতে পারে না। বদলে একটি রিলে loopback-এ বসে:

```
agent-client <--ws--> proxy (127.0.0.1) <--wss--> openmmo.to.nexus
                        |
                        +--> দর্শক (/mirror)
```

এজেন্টের পিছনে কিছু আছে, সার্ভার তা ঘুণাক্ষরেও জানে না। মাঝখানে থাকার সুবাদে রিলে সার্ভারের প্রতিটি বার্তার নকল একটি কেবল-পাঠযোগ্য দর্শক-দৃশ্যে পাঠাতে পারে। **রিলে কেবল `127.0.0.1`-এ শোনে, তাই কিছুই আপনার মেশিন ছেড়ে যায় না।**

## খেলার পর্দা

উপরের বার দেখায় সংযোগের অবস্থা, প্রাণসংকেত, দর্শক-দৃশ্যের মেমরি ব্যবহার, 3D দৃশ্য ফের লোড করার বোতাম, হাতে/AI সুইচ, এবং চরিত্র বা সার্ভার বদলানোর বোতাম। এজেন্ট চলার সময় কোনো সেটিং বদলালে **প্রয়োগ করে পুনরারম্ভ** বোতাম দেখা দেয়।

বাঁ দিকের পাটি ছয়টি ড্রয়ার খোলে:

| ড্রয়ার | কী দেখায় |
|---|---|
| সরঞ্জাম | কী পরা আছে, ঘর ধরে ধরে |
| থলি | কী বহন করা হচ্ছে, আর কোন আইটেম এজেন্ট বেচতে বা ফেলতে পারে |
| ব্যক্তিত্ব ও স্মৃতি | এই চরিত্রের নিজস্ব prompt (সম্পাদনযোগ্য) এবং এজেন্ট যা লিখে রেখেছে (কেবল-পাঠযোগ্য) |
| স্থানাঙ্ক | জায়গার বুকমার্ক, “বর্তমান অবস্থান ব্যবহার করুন” সহ |
| সংরক্ষিত নির্দেশ | প্রায়ই লাগে এমন নির্দেশ এক-ক্লিক বোতাম হিসেবে রাখা |
| কার্যকলাপ | দুটি ট্যাব: ভাবনা (প্রতিটি prompt ও উত্তর) এবং লগ (এজেন্ট প্রসেসের আউটপুট) |

প্রতিটি ড্রয়ারের বিস্তারিত আছে [প্যানেল রেফারেন্সে](../panel/)।

খেলার দৃশ্যের নিচে আটকানো **নির্দেশ** হলো চলমান এজেন্ট পর্যন্ত পৌঁছানো একমাত্র নিয়ন্ত্রণ: একটি নির্দেশ লিখুন, সেটি চরিত্রের পরের দফা হিসেবে পৌঁছাবে, **যথাসাধ্য — মানা হবেই তার নিশ্চয়তা নেই।**

## আপনার চাবিগুলো কোথায় থাকে

API চাবি ও সংযোগ-প্রোফাইলের secret OS-এর keychain দিয়ে এনক্রিপ্ট করা হয় (Electron-এর `safeStorage`, বিকল্পে AES-GCM) এবং এজেন্টকে পরিবেশ চলক হিসেবে দেওয়া হয় — **কখনোই `config.toml`-এ লেখা হয় না।** বাগ রিপোর্টে সেঁটে দেওয়া কনফিগে কোনো পরিচয়পত্র থাকে না।

## সমস্যা সমাধান

**প্রোটোকল সংস্করণ মেলেনি** — সার্ভার হালনাগাদ হয়েছে। [ডাউনলোড পৃষ্ঠা](../download/) থেকে নতুন বিল্ড নিন।

**সেটিং বদলেছি, কিছুই হলো না** — এজেন্ট তার কনফিগ চালু হওয়ার সময় একবারই পড়ে। উপরের বারে **প্রয়োগ করে পুনরারম্ভ** চাপুন।

**VS Code টার্মিনাল থেকে চালিয়েছি, কখনো খোলেই না** — VS Code নিজেই একটি Electron অ্যাপ এবং `ELECTRON_RUN_AS_NODE=1` গলিয়ে দেয়, ফলে ক্লায়েন্ট সাদামাটা Node হিসেবে চালু হয়:

```bash
env -u ELECTRON_RUN_AS_NODE npm start
```

**দর্শক-দৃশ্যে কিছু নেই বা জমে আছে** — স্বয়ংক্রিয় খেলার দর্শক-দৃশ্য একটি snapshot থেকে শুরু হয়, তাই এজেন্ট জানে কিন্তু এখন অনুসরণ করছে না এমন সবকিছু দৃষ্টিতে ফেরার সঙ্গে সঙ্গে দেখা দেয়।
