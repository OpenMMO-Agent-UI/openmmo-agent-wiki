게임 업데이트는 **프로토콜 버전**을 축으로 정리합니다 — 서버가 프로토콜 버전을
정확히 대조하기 때문에, 프로토콜이 바뀌면 옛 클라이언트는 아예 접속하지 못합니다.
그래서 이 축은 두 가지 질문에 동시에 답합니다: 「게임이 뭐가 바뀌었나」와
「클라이언트를 다시 받아야 하나」.

## 분류

| 표기 | 의미 |
|---|---|
| 신규 시스템 | 새로 추가된 게임 메커닉 |
| 밸런스 | 수치, 경제, 드랍률 변경 |
| 신규 아이템·에셋 | 새 무기, 방어구, 모델, 음악 |
| 수정 | 버그 수정 |
| 성능 | 실행 효율과 로딩 속도 |
| 클라이언트 | 데스크톱 클라이언트에만 영향, 게임 서버와 무관 |

## 프로토콜 v44 — 클라이언트 미출시

**업스트림에는 있지만 라이브 서버에는 아직 배포되지 않았습니다.** v41부터
여기까지는 코드에만 있는 변경이며, 라이브 서버는 여전히 v40을 요구합니다.


**신규 시스템**

- **인접한 두 방에 걸치는 형태를 포함해, 2칸짜리 여닫이 양문이
  추가되었습니다**(2026-08-28) — "double-door"라는 새 벽 변형이
  연속된 두 벽 구간을 하나의 2m 너비 개구부와 좌우 대칭 문짝
  두 짝으로 그립니다. 한쪽 방만 벽 끝에 반쪽 문을 놓았을 때
  인접한 방의 맞닿은 구간이 자동으로 짝을 이루어, 각 방이 공유
  경계를 가로지르는 자기 쪽 문짝을 그립니다(그 모서리의 기둥은
  생략됩니다). 여닫이는 양쪽이 함께 열리고 통행 판정도 같이
  처리됩니다. 맵 에디터의 벽 변형 순환에 새 옵션이 포함되어
  짝짓기와 해제를 자동으로 처리하며, 짝수 너비 방 템플릿은
  이제 가운데에 양문을 배치합니다.
- **같은 층에서 인접하고 용마루가 평행한 박공지붕이 자동으로
  하나로 합쳐집니다**(2026-08-28) — 너비가 같으면 용마루 방향으로,
  길이가 같으면 용마루를 가로질러 합쳐지며 그만큼 용마루가
  높아집니다. 상한을 넘는 방 수가 가로 방향으로 합쳐지려 하면
  길이가 비슷한 여러 구간으로 나뉘어 V자 골짜기에서 만나고
  (골짜기 쪽에는 처마를 만들지 않습니다), 방의 충돌 범위도
  합쳐진 용마루 높이에 맞춰 다시 계산됩니다.

**신규 아이템·에셋**

- **돌 벽난로(Stone Hearth)**(2026-08-28) — 가구류, 가치 1골드
  2000동화. 방패 문장이 새겨진 오래된 돌 벽난로로 천장까지
  닿으며, 불꽃 파티클과 광원이 딸려 있습니다. 맵 에디터에서
  바로 복제해 배치할 수 있습니다.

**성능**

- **주택을 드나들 때의 끊김 현상을 수정했습니다**(2026-08-28) —
  주택에 들어갈 때 원래 같은 프레임 안에서 실외 오브젝트 클론을
  전부 해체하고 실내 클론과 각각의 불꽃 파티클 시스템을 새로
  만들었는데, 이 순간적인 가비지와 GPU 바인드 그룹 재생성이
  실측 43~105ms의 끊김을 일으켰습니다. 이제 오브젝트 클론과
  불꽃 시스템을 상시 캐시에 유지하고 걸러질 때는 씬 그래프에서
  잠시 떼어내기만 하므로, 드나들기가 단순 재부착이 되어 반복
  테스트에서 프레임당 25ms 밑으로 유지됩니다.

## 프로토콜 v43 — 클라이언트 미출시

**신규 시스템**

- **친구 패널에서 이름을 직접 입력해 요청을 보낼 수 있고, 각 친구
  옆에 직업 아이콘이 표시됩니다**(2026-08-28) — 패널에 새로 생긴
  "+ Add" 입력창은 `/friend add <이름>`을 입력한 것과 같은 요청을
  보내며, 채팅창으로 옮겨갈 필요가 없습니다. 각 친구 이름 옆에는
  직업 아이콘이 표시되며, 파티 패널과 같은 아이콘 세트와 글자
  배지 대체 방식을 그대로 씁니다. 자세한 내용은
  [친구 시스템](../guides/friends/)을 참고하세요.

**수정**

- **지형 타일이 캐시에서 밀려날 때 가끔 자기 발밑 타일이 클릭 목록에서
  사라져, 집 배치 미리보기와 클릭이 그 자리에서 먹통이 되던 문제를
  수정했습니다**(2026-08-28) — 지형 타일 메쉬는 원래 인덱스 기반
  배열에 묶여 있었는데, 스트리밍으로 타일이 밀려나면 남은 타일들의
  인덱스는 앞으로 당겨지지만 바인딩은 따라가지 않아서, 서 있는
  타일이 엉뚱한 바인딩과 연결되거나 아예 연결되지 않을 수
  있었습니다. 이제 타일 id로 메쉬를 바인딩합니다.
- **주택 2층으로 가져간 횃불이 더 이상 바닥을 비추지 않습니다**
  (2026-08-28) — 횃불 조명은 원래 지형 높이를 다시 샘플링했는데,
  2층에서는 이 값이 1층 바닥 높이로 계산되었습니다. 이제 소지자의
  이미 해석된 층 Y좌표를 사용합니다.
- **같은 층의 두 방이 벽을 공유할 때 박공 창문이 더 이상 잘못
  잘려나가지 않습니다**(2026-08-28) — 원래는 내벽으로 취급되어
  제거되었는데, 이제 그렇지 않습니다.

## 프로토콜 v41–v42 — 클라이언트 미출시

**신규 시스템**

- **상인 가격이 서버 전체 골드 총량에 따라 천천히 움직이기 시작하며,
  소모품 구매가에 물가 지수가 적용됩니다**(v41, 2026-08-27) — 서버가
  매시간 서버 전체 골드 스냅샷을 기록하고 활성 캐릭터(최근 30일 접속)
  1인당 골드를 계산한 뒤, 이 지표의 변동폭에 따라 90%~200% 사이의
  물가 지수를 조정합니다. 이 지수는 상인의 **소모품**(물약, 숫돌 기름,
  음식, 주문서 등) 구매가에만 곱해지며, 장비나 염료 같은 내구재와
  모든 되팔기 가격은 영향을 받지 않습니다.
- **물가 조정이 상인 회의 장면으로 연출되어, Rica와 Wick이 대화에서
  가격 이야기를 합니다**(v42, 2026-08-27) — 조정은 고정된 시각이
  아니라 작은 달 Serin(주기 20게임일)이 하루 종일 어두운 날의
  일몰 후에 일어나며, 실시간 기준 약 2.5일마다 한 번씩입니다. 그
  시각이 되면 Rica와 Wick이 Rica의 가게에 모여 짧은 회의 장면을
  연출하고, 대화 중에 가격이 어느 방향으로 왜 움직이는지 힌트를
  흘립니다 — 엿들으면 다음 변동을 남들보다 먼저 알 수 있습니다.
  회의 한 번에 지수는 최대 ±10퍼센트포인트까지만 움직입니다.
  자세한 내용은
  [상점과 경제](../database/economy/#물가-지수저녁-상인-회의)를
  참고하세요.

**신규 아이템·에셋**

- **천문 회중시계(Celestial Timekeeper)**(2026-08-27) — 8,000
  동화, Rica 판매. 해와 달의 움직임을 추적하는 황동 회중시계로,
  지니고 있으면 하늘 위젯 옆에 현재 시각과 날짜가 표시됩니다.

**수정**

- **다리 위를 걷는 것이 더 이상 물에 젖은 것으로 잘못 판정되지
  않습니다**(2026-08-27) — "젖음" 판정은 원래 플레이어가 보고한
  XZ 좌표만으로 수심을 조회했고 다리 위인지는 신경 쓰지 않았기
  때문에, 강을 가로지르는 다리를 건너도 젖었습니다. 이제 서버가
  오브젝트 카탈로그와 실제 배치 데이터로 지역별 다리 갑판
  인덱스를 만들어, 갑판 위에서 내딛는 걸음은 클라이언트가 보고한
  Y값을 신뢰하지 않고 예외 처리합니다.
- **지면 높이를 이제 서버가 판정해, 좌표 보고를 이용한 공중 부양·
  땅속 잠수 편법을 막습니다**(2026-08-27) — 개활지에서 캐릭터의
  Y좌표는 원래 클라이언트의 보고를 그대로 믿었기 때문에, 시각적으로
  날아오르거나 땅속에 가라앉거나, 떨어뜨린 아이템이 공중에 뜨거나,
  던전 범위 안에서 클라이언트가 자기 마음대로 충돌 격자를 고를 수
  있었습니다. 이제 항상 서버가 높이맵이나 다리 갑판 곡선으로
  계산하며, 층 이동이나 로그인 시에도 다시 보정됩니다. "젖음"의
  수심 판정도 같은 로직을 쓰므로, 다리 아래로 물을 건너면 여전히
  젖습니다.

**클라이언트**

- **아이템 툴팁에 현재 장착 중인 장비와의 비교가 추가되었습니다**
  (2026-08-27) — 아이템에 마우스를 올리면 무게, 평균 피해, Guard
  차이가 ▲▼ 행으로 표시되며, 좋아지면 하늘색, 나빠지면 빨간색입니다.
  비교 대상은 서버의 대체 슬롯 규칙을 따르므로, 예를 들어 반지는
  빈 반지 슬롯이 남아 있으면 비교 항목이 표시되지 않습니다.
- **캐릭터 상태 창의 Guard와 CHA가 장비를 반영한 실시간 값으로
  바뀌었습니다**(2026-08-27) — 더 이상 생성 시 정해진 기본값이
  아니라 장비를 바꾸는 즉시 갱신되며, 표시되는 CHA가 바로 흥정에
  실제로 쓰이는 값입니다.

## 프로토콜 v39–v40 — 클라이언트 v0.36.0 (현재 버전)

**라이브 서버는 현재 v40을 요구합니다.** 이전 클라이언트는 접속이 거부됩니다.

**신규 시스템**

- **레벨업에 필요한 경험치가 단순 배증 곡선 대신 플레이 시간 기준 구간표를
  따릅니다**(v39, 2026-08-27) — 예전 공식은 XP(n) = 20 × 2^(n-2)로 매
  레벨마다 두 배가 되어, 초반은 어이없이 빠르고 20레벨을 넘으면 사실상
  도달 불가능했습니다. 새 곡선은 2~50레벨을 실측 페이스로 구간표를 짰습니다:
  하루 4시간 플레이하는 표준 유저 기준으로 2~10레벨은 레벨당 약 5분에서
  22분(누적 약 2시간), 10~30레벨은 22분에서 5.5시간(대략 하루 한 번),
  30~50레벨은 5.5시간에서 8시간(후반은 이틀에 한 번쯤)이며, 50레벨까지
  총 약 199.5시간(50일)이 걸립니다. 50레벨을 넘으면 다시 배증이
  적용됩니다. 기존 캐릭터의 경험치는 "현재 레벨 구간 안의 진행률을
  그대로 유지"하는 방식으로 옮겨져, 표를 바꿨다고 레벨이 오르내리지
  않습니다. 패킷 형식은 바뀌지 않았지만 구버전 클라이언트는 여전히 옛
  표로 경험치 게이지를 그리므로, 프로토콜 버전을 올려 강제로 새로고침을
  유도합니다. 자세한 내용은 [전투 시스템](../guides/combat/#레벨업에-필요한-양)을
  참고하세요.
- **새 디버프 "젖음": 물에 들어가면 이동이 느려지고 갑옷이 젖습니다**
  (v40, 2026-08-27) — 강이나 바다에 들어가 발밑 수심이 0.4m를 넘으면
  걸리며, 450초(게임 내 1시간) 지속됩니다. 이동 속도가 ×0.83으로
  떨어져(뛰기가 4.5에서 3.75로, 걷기 3.0과 뛰기 4.5의 중간이 됩니다)
  입고 있거나 가방에 든 **갑옷**(투구·갑옷·바지·장갑·장화·방패·양모
  망토 등 17종)은 물을 먹어 무거워집니다(갑옷 무게 ×1.5) — 많이 걸칠수록
  쓸 수 있는 최대 하중이 그만큼 줄어듭니다. 무기·횃불·낚싯대·악기·장신구는
  영향을 받지 않습니다. 물속을 계속 걸으면 지속시간이 갱신되며, 물에서
  나와야 마르는 시간이 시작됩니다. 불 켜진 모닥불 근처(3m 이내)에 있으면
  더 빨리 마르는데, 앉을 필요 없이 45초면 흠뻑 젖은 상태에서 완전히
  마릅니다. 젖어 있는 동안 뒤로 점점 옅어지는 젖은 발자국이 남습니다
  (다른 플레이어의 발자국은 그래픽 설정이 High일 때만 보이고, 본인
  발자국은 설정과 무관하게 항상 보입니다). 다리 위를 걷는 것은 젖음으로
  치지 않습니다. 자세한 내용은 [전투 시스템](../guides/combat/#디버프)을
  참고하세요.

**밸런스**

- **치유 물약의 월드 드랍률이 2%로 두 배가 되었습니다**(2026-08-27) —
  기존 1%에서 상향.
- **금지 이름 목록에 "administrator"가 추가되었습니다**(2026-08-27) —
  기존에는 "admin"만 막고 있어 "administrator"라는 완전한 문자열은
  걸러내지 못했습니다.

**성능**

- **지형 텍스처와 정적 에셋이 브라우저 캐시를 제대로 타게 되어, 반복
  로딩 트래픽이 크게 줄었습니다**(2026-08-27) — 지형 텍스처는 원래

**체력이 가득하거나 쓰러진 상태에서는 낭비하지 않고 그대로 남습니다.**
마실 때마다 하나가 소모되고 체력 변화가 근처 플레이어에게 방송됩니다.

**기타** ・ 아이템 데이터의 `damageDice` / `healDice` 두 열을 `category` + `dice`로
합쳤습니다. `category`가 `dice`의 해석 방식을 정합니다(무기 → 피해,
치유 물약 → 회복).

### 6/27 — 복도 문

**기타** ・ 복도가 방으로 들어가는 입구에 클릭해서 여는 나무 양문이 생겼습니다
(지상 입구와 같은 문짝과 석재 아치). 이전에는 그냥 뚫린 구멍이었습니다.

### 6/25 — 복도와 방의 벽 구분

**기타** ・ 던전 복도가 방과 다른 벽 텍스처를 씁니다. 방은 중세 석재를 유지하고
복도는 암벽이 되며, 텍스처가 바뀌는 지점에서 벽면이 끊어집니다.
**지금 복도에 있는지 방에 있는지 구분하는 데 쓸 수 있습니다.**

### 6/20 — 던전 클릭 길찾기 수정

**수정** ・ 던전 입구 계단의 클릭 버그를 고쳤습니다 — 방 안의 빨갛게 표시된 바닥을
클릭하면 플레이어가 지상으로 되돌아가던 문제입니다. 원인은 숨겨진 지상 입구
건물이었습니다: Three.js의 레이캐스트는 **보이지 않는 오브젝트에도 맞기 때문에**
그 벽과 지붕이 지하층 클릭을 가로채고 있었습니다.

### 6/18 — 부술 수 있는 소품, 상호작용 상자와 동전

**신규 시스템** ・ 나무통과 상자를 **부술 수 있습니다** — 클릭하면 캐릭터가 다가가
한 번 휘두르고, 접촉하는 프레임에서 모델 전체가 부서진 버전으로 교체됩니다
(보물 상자는 부서지지 않음). 서버 권위 판정이며 부서진 칸은 통행 가능해집니다.

**신규 시스템** ・ 보물 상자와 **상호작용**할 수 있습니다 — 클릭하면 다가가 뚜껑을
엽니다. 열면 상자 앞에 실제 동전 무더기 지상 아이템이 생성되고, 주우면
**1–10 동화가 지갑으로 바로** 들어갑니다. 가방 칸을 차지하지 않습니다.

### 6/17 — 계단 통행성

**수정** ・ 통행 플래그를 막아 현재 층의 몬스터가 계단의 높은 쪽으로 들어가지
못하게 했습니다 — 원래는 수직 통로를 타고 올라가 위층 바닥을 뚫고 나왔습니다.

### 6/15 — 횃불 그림자 아티팩트

**수정** ・ 던전 횃불 조명의 그림자 문제를 고쳤습니다. 핵심은 three.js가 기본적으로
**뒷면**에서 그림자 맵을 기록한다는 점입니다. 이렇게 하면 자체 오프셋으로
아크네를 피할 수 있지만 접촉 그림자가 떠 보입니다. 0.02미터의 접촉 리프트를 더하고
더 큰 그림자 맵과 더 작은 바이어스를 함께 적용해 해결했습니다.

### 6/14 — 절차 생성 던전

**신규 시스템** ・ **시드로 결정되는** NetHack 스타일 미로 던전이 추가되었습니다.
입구마다 고정이고 최대 20층입니다. 지상 입구는 주택의 절차 기하를 재사용한 석조
건물이고, 지형에 구멍을 뚫어 계단을 드러냅니다.
**최하층에는 전리품을 든 보스가 있습니다.**

### 6/11 — 경제 2단계: LLM 흥정

**신규 시스템** ・ Rica의 LLM이 새 `offer_deal` 액션으로 **플레이어별 전용** 가격
혜택을 줄 수 있게 되었습니다. 서버는 제시가를 CHA로 결정되는 가격대 안에 가두고,
일일 예산과 쿨다운을 강제하며, 모든 결정을 기록합니다. 거래창에는 흥정된 가격이
표시됩니다.

CHA 연동 가격대는 약 ±5~25%p, 상인은 게임 하루에 1골드, 플레이어당 40실버,
흥정 쿨다운 30초, 성사된 혜택은 **1회용이며 5분 뒤 만료**됩니다.
