게임 업데이트는 **프로토콜 버전**을 축으로 정리합니다 — 서버가 프로토콜 버전을
정확히 대조하기 때문에, 프로토콜이 바뀌면 옛 클라이언트는 아예 접속하지 못합니다.
그래서 이 축은 두 가지 질문에 동시에 답합니다: 「게임이 뭐가 바뀌었나」와
「클라이언트를 다시 받아야 하나」.

## 분류

| 표기 | 의미 |
|---|---|
| 신규 시스템 | 새로 추가된 게임 메커닉 |
| 밸런스 | 수치, 경제, 드랍률 변경 |
| 신규 아이템·에셋 | 새 무기, 방어구, 모델, 음악 |
| 수정 | 버그 수정 |
| 성능 | 실행 효율과 로딩 속도 |
| 클라이언트 | 데스크톱 클라이언트에만 영향, 게임 서버와 무관 |

## 프로토콜 v23–v25 — 클라이언트 v0.21.0 (현재 버전)

**라이브 서버는 현재 v25를 요구합니다.** 이전 클라이언트는 접속이 거부됩니다.
세 프로토콜 버전이 나흘(8/6–8/10)에 걸쳐 각각 배포되었고, 서로 다른 세
시스템입니다: 친구, 상인 좌판, 거래 제안 거절.

**신규 시스템**

- **친구 시스템**(v23) — `/friend add <이름>`(또는 `/f`)으로 친구 요청을
  보내면 상대가 알림창에서 120초 안에 수락해야 성립합니다. 서로 동시에
  요청을 보내면 답할 필요 없이 바로 친구가 됩니다. **F** 키로 친구 패널을
  열면 클릭 한 번으로 귓속말이나 파티 초대를 할 수 있습니다. 친구와 차단은
  양립할 수 없어서, 친구를 차단하면 친구 관계가 즉시 해제됩니다. 전체 규칙은
  [친구 시스템](../guides/friends/)에.
- **상인 좌판**(v24) — 새 명령 `/lay_stall`은 상인 클래스 전용으로, 야외에서
  「영업 중」을 알리는 매대를 펼칩니다(`/pack_stall`로 접고, 로그아웃해도
  자동으로 접힙니다). 순수한 소품이며 거래 자체는 기존 창 그대로입니다.
- **거래 제안 거절**(v25) — NPC가 먼저 걸어오는 거래·제안 창에 「지금은
  됐어요」 버튼이 생겼고, 응답 없이 시간이 지나 사라져도 거절로 처리됩니다.
  거절하면 **같은 NPC는 10분 동안 다시 제안을 걸어오지 않습니다.**

**밸런스**

- **야간 상인 Wick**이 Aldermark 대로에서 해가 진 뒤 영업을 시작합니다.
  횃불, 치료 물약, 모닥불 키트, 빵, 육포, 귀환 스크롤 같은 야간 필수품만
  팔고, 매입가는 기준가의 **30%**입니다(Rica는 40%) — 아침까지 기다리는
  것보다 이득인 경로가 아니라 순수한 야간 편의입니다.
- **Rica는 잠든 동안 거래할 수 없습니다**(2026-08-05) — 밤에 침대에 있는
  동안은 상점 창이 열리지 않고(이미 열려 있던 것도 닫힙니다), 이것이 바로
  Wick이 생긴 이유입니다: 마을이 밤새 문 연 곳 하나 없이 지낼 수는 없으니까요.
- 경비병 **Karl** 같은 편제 NPC는 이제 **접속할 때 지정 장비가 자동으로
  지급되고 착용됩니다**(장창 + 가죽 갑옷 한 벌), 모델 기본 외형에 의존하지
  않습니다. 지급 장비는 NPC가 팔든 플레이어가 팔든 **판매가 불가능**해서,
  접속·해제를 반복해 장비를 공짜로 얻는 수법을 막습니다.
- **NPC는 당신을 기억합니다(호감도)** — NPC가 이제 최근 대화 30줄을 돌려가며
  기억하고, 바드는 추가로 최근 연주한 8곡을 기억합니다. 대화는 서버에 저장되는
  **호감도** 수치도 쌓는데(턴당 ±1, 누적 최대 ±5), 문턱을 넘은 플레이어는
  NPC가 개인 거래를 제안할 단골로 대하기 시작합니다 —
  [음악과 바드](../guides/music/)의 애장품 거래를 움직이는 메커니즘입니다.

**수정**

- NPC 에이전트 프로세스가 비정상 종료되면 driver가 잠시 뒤 자동으로 재시작해서,
  그대로 사라져 버리지 않습니다.
- 던전 안에서 지상 오브젝트(상점 간판 등)가 허공에 떠 보이던 문제를 수정했습니다.
- 서버가 던전 층 이동을 보정할 때 계단과 어긋나게 정렬되던 문제를 수정했습니다.
- 서버가 거부한 이동(60m 초과, 사망한 플레이어, 비정상 좌표 등)이 이제
  위치 보정 패킷을 확실히 돌려받아서, NPC 에이전트가 「유령 이동」에 걸려
  제자리를 오가는 문제가 사라졌습니다.

## 프로토콜 v20–v22 — 클라이언트 v0.20.0

세 프로토콜 버전이 이틀(8/6–8/7) 사이에 연달아 배포되었고, 전부 한 가지
주제입니다: **음악 시스템**. 플레이 방법은 [음악과 바드](../guides/music/)에.

**신규 시스템**

- **음악 연주**(v20) — 새 이모트 명령 `/play_music [곡명]`: 인벤토리에 악기가
  있으면 누구나 연주할 수 있습니다. 곡명은 조각 매칭을 지원하고 비워 두면
  무작위. 근처의 모두에게 들리고 채팅에 곡명이 공지됩니다.
- **청중 경험**(v21) — 공연 중에는 배경음악이 자리를 비켜 주고, 곡 중간에
  다가온 사람도 처음부터가 아니라 진행 중인 지점부터 함께 듣습니다.
- **팁과 아이템 전달**(v22) — 캐릭터 사이에 아이템이 오가는 모습이 이제
  모두에게 보입니다. 동전이나 잡동사니를 바드의 발치에 떨어뜨리면 누가 준
  것인지 기억합니다.
- **바드 클래스** — 플레이어가 선택할 수 있는 새 클래스: 생명 주사위 d6,
  DEX +2, CHA +2, STR −2, CON −1, WIS −1, 낡은 만돌린을 들고 시작합니다.
- **상주 바드 NPC Signe**가 마을 광장에서 버스킹을 시작했습니다 — 하루 종일
  연주하고, 곡 사이에 신청곡을 받고, 밤에는 모닥불을 피우고, 아침마다 어제의
  팁을 Rica에게 팝니다. 그녀의 금장 만돌린은 **애장품(keepsake)**: 재고에는
  보이지 않고, 마음에 든 단골에게 개인 제안으로만 팝니다.

**신규 아이템·에셋**

- **만돌린**(40 은화)과 **낡은 만돌린**(판매 불가) — 새 *악기* 카테고리의 첫
  두 아이템. 전용 모델과 `/play_music` 연주 자세가 함께 들어왔습니다.

**밸런스 조정**

- **무기 강화 주문서** 월드 드랍률 0.4% → **1%**(2026-08-05) — 기대값은
  100마리당 한 장.

## 프로토콜 v19 — 클라이언트 v0.19.0

**신규 아이템**

- **렘바스 웨이퍼**(Lembas Wafer) — 엘프의 여행용 빵. 포만도 600, 무게 0.15 kg,
  60 동화. **kg당 효율이 전체 음식 중 1위**(4000/kg, 빵은 540)라 장거리 이동에
  최적입니다. Rica가 판매를 시작했습니다.

## 프로토콜 v17 — 클라이언트 v0.18.0

중간 버전입니다. 서버가 이미 v19로 넘어갔으므로 이 클라이언트 버전도 접속할 수
없습니다.

## 클라이언트 업데이트 (게임 서버와 무관)

**클라이언트** ・ **설정 탭 개편**(v0.18부터) —
기존 Automatic play와 Advanced가 **Agent**로 합쳐지고,
Actions는 **Display**로 이름이 바뀌었으며, **Audio** 탭(BGM·효과음 음량)이
새로 생겼습니다.

**클라이언트** ・ 헤더에 **일시정지 버튼** 추가. 멈춰 있는 동안 LLM을 호출하지
않으므로 비용이 발생하지 않습니다 — 잠깐 직접 조종하거나 비용을 아낄 때 쓰세요.

**클라이언트** ・ 금액이 **1골드 = 100실버 = 10,000동화** 단위로 표시됩니다.
더 이상 긴 동화 숫자 하나가 아닙니다.

## 그 사이에 함께 배포된 변경

아래는 v17–v22 사이에 별도의 프로토콜 버전 없이 적용된 것들로, 현재 서버와
클라이언트에 모두 포함되어 있습니다.

**밸런스**

- **식량 전면 재조정**(2026-08-04). 빵이 「하루 한 끼」의 주력이 되고,
  육포는 가볍게 들고 다니는 쪽으로 바뀌었습니다:

  | 음식 | 포만도 | 무게 | 가격 |
  |---|---:|---:|---:|
  | 빵 | 180 → **540** | 0.5 → **1 kg** | 8c → **20c** |
  | 육포 | 540 → **300** | 0.5 → **0.25 kg** | 40c → **30c** |
  | 치즈 | 300 → **180** | 0.5 → **0.4 kg** | 20c → **12c** |
  | 사과 | 60(변동 없음) | 0.3 kg | 3c |

  전체 효율 비교는 [음식과 포만도](../database/food/)를 보세요.

**신규 시스템**

- **HUD 미니맵**, 시간 위젯 아래에 표시(끌 수 있음). 지형지물과 월드맵 마커도 개선.
- **운영 명령어**: `/kick`, `/mute`, `/summon`, `/goto`.

**수정**

- 한 계정당 하나의 세션만 허용.
- 다른 세션에서 사용 중인 캐릭터의 삭제 거부.
- 서버 측에서 플레이어 공격 간격 강제.
- 던전 상자 이력을 불러오지 못하면 게임 입장 거부(fail-closed).
- 파티 위치를 각 클라이언트가 폴링하지 않고 서버가 푸시 — 에이전트를 깨우지도 않음.
- 음유시인 NPC가 접속 시 낡은 만돌린을 장착하도록 수정 — 금장 애장품은 가방에 남아
  단골에게 몰래 제안하는 흐름을 막지 않습니다(2026-08-07).

## 프로토콜 v16 — 클라이언트 v0.17.0 대응

**신규 시스템**

- **허기/포만도 시스템**을 엔드투엔드로 구현. 캐릭터 상태 탭에 허기 효과가 추가되고,
  HUD에 포만도와 툴팁이 표시됩니다.
- **모닥불 시스템** 재작업 — 기존의 절차 생성 모닥불을 대체하고 불꽃 표현과
  설치 판정을 조정했습니다.
- 음식을 모닥불에 **구울 수** 있습니다(아이템 데이터의 `grillsInto` 열).

**밸런스**

- **아이템 경제 전면 재조정**과 무기 티어 사다리 정리.
- 환경 몬스터 생성이 **서버 허용량을 요구**하도록 변경 — 클라이언트가 임의로
  결정하지 않습니다.
- 몬스터 드랍이 **치명타가 들어갈 때까지 서버가 보류**하도록 변경 —
  가로채기와 중복을 막습니다.

**신규 아이템·에셋**

- `ring_of_protection`(보호의 반지), 십자 방패 반지 장신구 모델과 함께 추가.
- 단검이 전용 모델과 아이콘을 갖게 됨.
- 화려한 십자 벨트 모델과 아이콘.

**기타**

- 월드맵이 **이미 발견한 던전 입구를 기록**합니다.
- 파티 초대에 **카운트다운 게이지**가 표시됩니다.
- 횃불 파티클 렌더링 수정.

## 2026년 7월

### 7/17 — Google 로그인

**신규 시스템** ・ 비밀번호 로그인이 Google 로그인으로 전면 교체되었습니다.
로그인 화면에는 Google 버튼 하나만 남고 서버가 ID 토큰을 검증합니다.
기존 비밀번호 경로는 보안상의 이유로 폐지되었습니다.

새 계정은 무작위 `player_xxxxxx` 이름을 받고, **이메일이나 프로필 이름은 저장하지
않습니다.**

### 7/16 — 보조손 방패, 가구가 이동을 막음

**신규 아이템** ・ 나무 방패와 까마귀 방패가 추가되었고, 각각 Guard 값을 가져
전투 계산에 실제로 반영되며 캐릭터 시트에 표시됩니다.

**신규 시스템** ・ 실체가 있는 가구가 자기가 놓인 칸을 막아, 플레이어와 NPC가
통과하지 않고 **돌아갑니다.** 충돌 판정은 공유되는 Rust 코드라 브라우저, 봇,
서버가 「어느 칸이 막혔는지」에 대해 완전히 같은 인식을 갖습니다.

### 7/14 — Rica의 가게 단장

**기타** ・ 절차 생성된 「Rica's General Store」 간판을 달고, 아이템 모델을 가구로
써서 가게 내부를 꾸몄으며, 재고를 갱신해 치유 물약과 귀환 주문서를 팔기 시작했습니다.

### 7/13 — 월드 수평 순환

**수정** ・ 절반만 되어 있던 X축 순환을 완성했습니다 — 동서 양끝이 실제로
이어지고, 대체 지형이나 멈춰버린 지도 마커가 더 이상 나오지 않습니다.

### 7/12 — 수면 셰이더 재작업

**기타** ・ 바다와 강 셰이더를 다시 쓰고 하나로 통일해 경계가 매끄럽게 섞이도록
했습니다. 파도 움직임을 개선하고, 강 속 장애물(바위, 교각) 주위에 물보라를
추가했습니다.

## 2026년 6월

### 6/30 — 퀵슬롯 바

**신규 시스템** ・ 화면 하단에 **10칸 퀵슬롯**이 추가되었습니다. 가방 아이템을
슬롯에 끌어다 놓으면 연결되고(아이콘과 남은 개수 표시), **더블클릭 또는 해당
숫자키**(1–9, 그다음 0)로 사용합니다 — 장착 가능한 것은 장착되고 소모품은
사용됩니다. 우클릭으로 해제합니다.

연결은 개별 인스턴스가 아니라 아이템 **정의** 기준이라, 한 묶음을 다 쓰고 같은
것을 다시 얻어도 연결이 유지됩니다. 캐릭터별로 브라우저 로컬에 저장됩니다.
하단 HUD도 정리해 채팅, 퀵슬롯, 메뉴 버튼을 한 줄에 합쳤습니다.

### 6/28 — 치유 물약

**신규 시스템** ・ 첫 번째 마시는 소모품입니다. 가방에서 치유 물약을 더블클릭하면
서버가 **6d4** HP(NetHack 주사위)를 굴리며 상한은 최대 체력입니다 —
**체력이 가득하거나 쓰러진 상태에서는 낭비하지 않고 그대로 남습니다.**
마실 때마다 하나가 소모되고 체력 변화가 근처 플레이어에게 방송됩니다.

**기타** ・ 아이템 데이터의 `damageDice` / `healDice` 두 열을 `category` + `dice`로
합쳤습니다. `category`가 `dice`의 해석 방식을 정합니다(무기 → 피해,
치유 물약 → 회복).

### 6/27 — 복도 문

**기타** ・ 복도가 방으로 들어가는 입구에 클릭해서 여는 나무 양문이 생겼습니다
(지상 입구와 같은 문짝과 석재 아치). 이전에는 그냥 뚫린 구멍이었습니다.

### 6/25 — 복도와 방의 벽 구분

**기타** ・ 던전 복도가 방과 다른 벽 텍스처를 씁니다. 방은 중세 석재를 유지하고
복도는 암벽이 되며, 텍스처가 바뀌는 지점에서 벽면이 끊어집니다.
**지금 복도에 있는지 방에 있는지 구분하는 데 쓸 수 있습니다.**

### 6/20 — 던전 클릭 길찾기 수정

**수정** ・ 던전 입구 계단의 클릭 버그를 고쳤습니다 — 방 안의 빨갛게 표시된 바닥을
클릭하면 플레이어가 지상으로 되돌아가던 문제입니다. 원인은 숨겨진 지상 입구
건물이었습니다: Three.js의 레이캐스트는 **보이지 않는 오브젝트에도 맞기 때문에**
그 벽과 지붕이 지하층 클릭을 가로채고 있었습니다.

### 6/18 — 부술 수 있는 소품, 상호작용 상자와 동전

**신규 시스템** ・ 나무통과 상자를 **부술 수 있습니다** — 클릭하면 캐릭터가 다가가
한 번 휘두르고, 접촉하는 프레임에서 모델 전체가 부서진 버전으로 교체됩니다
(보물 상자는 부서지지 않음). 서버 권위 판정이며 부서진 칸은 통행 가능해집니다.

**신규 시스템** ・ 보물 상자와 **상호작용**할 수 있습니다 — 클릭하면 다가가 뚜껑을
엽니다. 열면 상자 앞에 실제 동전 무더기 지상 아이템이 생성되고, 주우면
**1–10 동화가 지갑으로 바로** 들어갑니다. 가방 칸을 차지하지 않습니다.

### 6/17 — 계단 통행성

**수정** ・ 통행 플래그를 막아 현재 층의 몬스터가 계단의 높은 쪽으로 들어가지
못하게 했습니다 — 원래는 수직 통로를 타고 올라가 위층 바닥을 뚫고 나왔습니다.

### 6/15 — 횃불 그림자 아티팩트

**수정** ・ 던전 횃불 조명의 그림자 문제를 고쳤습니다. 핵심은 three.js가 기본적으로
**뒷면**에서 그림자 맵을 기록한다는 점입니다. 이렇게 하면 자체 오프셋으로
아크네를 피할 수 있지만 접촉 그림자가 떠 보입니다. 0.02미터의 접촉 리프트를 더하고
더 큰 그림자 맵과 더 작은 바이어스를 함께 적용해 해결했습니다.

### 6/14 — 절차 생성 던전

**신규 시스템** ・ **시드로 결정되는** NetHack 스타일 미로 던전이 추가되었습니다.
입구마다 고정이고 최대 20층입니다. 지상 입구는 주택의 절차 기하를 재사용한 석조
건물이고, 지형에 구멍을 뚫어 계단을 드러냅니다.
**최하층에는 전리품을 든 보스가 있습니다.**

### 6/11 — 경제 2단계: LLM 흥정

**신규 시스템** ・ Rica의 LLM이 새 `offer_deal` 액션으로 **플레이어별 전용** 가격
혜택을 줄 수 있게 되었습니다. 서버는 제시가를 CHA로 결정되는 가격대 안에 가두고,
일일 예산과 쿨다운을 강제하며, 모든 결정을 기록합니다. 거래창에는 흥정된 가격이
표시됩니다.

CHA 연동 가격대는 약 ±5~25%p, 상인은 게임 하루에 1골드, 플레이어당 40실버,
흥정 쿨다운 30초, 성사된 혜택은 **1회용이며 5분 뒤 만료**됩니다.
