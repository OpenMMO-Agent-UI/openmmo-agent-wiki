export const dName = (d) => dungeonNames[d.id] ?? d.name;

현재 **{dungeons.length}곳**이 열려 있습니다. 던전은 **시드로 결정**되므로
같은 입구는 들어갈 때마다 구조가 같고, 다시 생성되지 않습니다.

## 보스

<FilterTable
  placeholder="보스 검색…"
  columns={[
    { key: 'name', label: '보스' },
    { key: 'dungeon', label: '던전' },
    { key: 'level', label: '레벨', align: 'right' },
    { key: 'hp', label: '체력', align: 'right' },
    { key: 'guard', label: 'Guard', align: 'right' },
    { key: 'atk', label: '명중 보너스', align: 'right' },
    { key: 'dmg', label: '피해', align: 'center' },
    { key: 'drop', label: '확정 드랍 무기' },
  ]}
  rows={dungeons.filter((d) => d.boss).map((d) => {
    const m = monsters.find((x) => x.id === d.boss);
    return {
      name: monsterName(m.id), dungeon: dName(d),
      level: m.level, hp: m.healthEffective, guard: m.guard,
      atk: `+${m.attackBonusEffective}`, dmg: m.damageRollEffective,
      drop: m.weapon ? itemName(m.weapon) : '—',
    };
  })}
/>

**오크 워로드**는 격차가 큽니다 — 체력 120은 데이터에 직접 지정된 값이고
(레벨에서 유도되는 45가 아닙니다), Guard 13, 명중 +6, 피해 2d8입니다.
오크 소굴은 10층이니 가죽 세트를 갖추고 내려가는 것을 권합니다.

## 상자 드랍 규칙

각 던전의 상자 드랍은 세 부분입니다:

1. **확정 드랍(시그니처)** — 던전마다 하나씩 고정. 위 표의 「확정 드랍」 열.
2. **개별 굴림** — 해당 티어 풀의 나머지 장비를 각자의 확률로 한 번씩 굴립니다.
3. **하위 티어 보정** — 던전보다 낮은 티어의 장비는 각각 10% 추가 확률.
   상위 던전에서 놓친 부위를 메울 수 있습니다.

골드는 `깊이 × 500 ~ 깊이 × 1500`입니다.

설계 목표는 해당 티어에서 처음 나오는 부위를 모으는 데 **평균 약 5회**입니다.

<FilterTable
  placeholder="장비 검색…"
  columns={[
    { key: 'name', label: '장비' },
    { key: 'en', label: '게임 내 이름' },
    { key: 'tier', label: '상자 티어', align: 'center' },
    { key: 'chance', label: '드랍 확률', align: 'right' },
    { key: 'guard', label: 'Guard', align: 'right' },
    { key: 'cha', label: 'CHA', align: 'right' },
  ]}
  rows={items
    .filter((i) => i.chestTier)
    .sort((a, b) => a.chestTier - b.chestTier || (b.guard ?? 0) - (a.guard ?? 0))
    .map((i) => ({
      name: itemName(i.id), en: i.name,
      tier: `T${i.chestTier}`,
      chance: i.chestChance ? `${Math.round(i.chestChance * 100)}%` : '확정 드랍',
      guard: i.guard ?? '—',
      cha: i.chaBonus ? `+${i.chaBonus}` : '—',
    }))}
/>

:::note[무기는 상자에서 나오지 않습니다]
무기는 「그 무기를 든 몬스터가 드랍」으로 통일되어 있어, 보이는 것이 곧 얻을 수 있는
것입니다. 상자는 방어구와 장신구만 줍니다.
:::

## 던전에서 만나는 것

    .map((m) => ({
      name: monsterName(m.id), level: m.level,
      depth: `${m.dungeonMinDepth} – ${m.dungeonMaxDepth}층`,
      weight: m.dungeonWeight, hp: m.healthEffective, dmg: m.damageRollEffective,
    }))}
/>

## 던전 안의 다른 것들

- **통과 나무통과 상자를 부술 수 있습니다** — 클릭하면 캐릭터가 다가가 한 번 휘두릅니다.
  보물 상자는 부서지지 않습니다.
- **보물 상자는 여는 것** — 클릭하면 다가가 뚜껑을 열고, 앞에 동전 무더기가 떨어집니다.
  주우면 지갑으로 바로 들어갑니다(1–10 동화). 가방 칸을 차지하지 않습니다.
- **복도에 문이 있습니다** — 복도가 방으로 들어가는 입구에 나무 양문이 있고 클릭해서 엽니다.
- **복도와 방의 벽이 다릅니다** — 방은 중세 석재, 복도는 암벽입니다.
  지금 어디에 있는지 구분하는 데 쓸 수 있습니다.
