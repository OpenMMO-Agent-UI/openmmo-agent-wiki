## 데이터는 어떻게 만들어지나

`scripts/sync-gamedata.mjs`가 업스트림 저장소에서 `data-src/*.csv`를 받아
이 사이트의 `src/data/game/`에 저장합니다. 사이트를 빌드할 때 그 CSV를 직접 읽어
표를 만듭니다.

원본 CSV에는 없는데 여기서 하는 일이 두 가지 있습니다:

1. **유도값 채우기** — 몬스터의 체력, 명중 보너스, 피해 주사위는 데이터에서 비어
   있으면 「덮어쓰지 않음」을 뜻하고, 서버가 레벨에서 계산합니다.
   빈칸으로 보여주는 건 틀린 표시이므로 서버와 같은 공식으로 채우고,
   어떤 값이 유도된 것인지 표시합니다.
2. **화폐 환산** — 게임 내부는 동화 정수 하나만 저장하며,
   1골드 = 100실버 = 10,000동화는 표시 계층의 관례입니다.

업스트림이 수치를 바꾸면 동기화 스크립트를 다시 돌리는 것만으로 갱신됩니다.
