캐릭터를 만든 뒤에도 외모를 바꾸고 싶다면 알더마크의 미용사 Odette를 찾아가면
된다 — 옷가게 북쪽에 있는 Silver Comb Salon을 운영한다(프로토콜 v166). 바꿀
수 있는 건 **얼굴, 머리 모양, 머리색, 눈 색**뿐이고, 성별·직업·이름은 바뀌지
않는다.

## 사용 방법

살롱에 들어가 손님 의자에 앉으면 선택 창이 자동으로 열린다 — **Odette를
클릭해서 여는 게 아니다**. 의자가 Odette로부터 6미터 안에 있어야 하고, 그녀가
자고 있지 않아야(밤에 잠드는 시간이 아니어야) 열린다. 앉으면 Odette가 의자
뒤로 와서 서서 무엇을 바꿀지 물어본다. 선택 항목은 캐릭터 생성 화면과 같은
외모 선택기이며, 얼굴은 모델에 직접 들어가 있어서 얼굴을 바꾸면 캐릭터 모델을
다시 만든다.

## 가격

바뀐 항목만 **그만큼만 청구**되고, 건드리지 않은 항목은 무료다. 색을 "원래
색"으로 되돌리는 것도 변경으로 친다:

| 항목 | 가격 |
|---|---:|
| 얼굴 | 1금(동화 10,000개) |
| 머리 모양 | 50은(동화 5,000개) |
| 머리색(원래 색으로 되돌리기 포함) | 20은(동화 2,000개) |
| 눈 색(원래 색으로 되돌리기 포함) | 20은(동화 2,000개) |

아무것도 바뀌지 않았다면 청구할 금액이 없으므로 아무 효과 없는 요청으로
거절된다. 골드를 받는 것과 저장하는 것은 하나의 트랜잭션이라, 저장에
실패하면 받은 골드를 돌려준다.

## 거절되는 경우

- Odette로부터 **6미터보다 멀리** 있거나, 그녀가 자고 있을 때.
- **공식 NPC**이거나, 애초에 외모 선택 항목이 없는 직업(생성 시 얼굴/머리
  선택 화면을 건너뛰는 직업)일 때.
- **다른 플레이어와 거래 중**일 때.
- 바꾸려는 항목에 **골드가 모자랄** 때.

## 다 바꾸고 나면

의자에서 일어나면 Odette가 실제로 뭔가 바뀌었는지 살펴본다 — 바뀌었으면
칭찬을, 바뀌지 않았으면 다음에 또 오라는 인사를 건넨다. 주변에 있던 플레이어는
바로 새 모습을 보고, 나중에 다가온 플레이어도 이미 바뀐 모습을 보게 된다.
