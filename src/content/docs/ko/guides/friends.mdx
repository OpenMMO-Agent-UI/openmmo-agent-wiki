친구 시스템은 프로토콜 v23에서 추가되었습니다. 친구 관계는 **양쪽 모두의
동의**가 있어야 성립하며, 계정이 아니라 **캐릭터** 단위로 기록됩니다 —
같은 계정의 다른 캐릭터로 로그인하면 친구 목록은 비어 있습니다.

## 친구 추가하기

채팅에 입력합니다:

```
/friend add <이름>
```

`/f add <이름>`도 같은 축약형으로 사용할 수 있습니다.

- 상대는 **요청 알림창**을 받고 **120초 이내**에 수락하거나 거절해야
  합니다. 응답이 없으면 요청은 그냥 만료됩니다.
- **둘 다 상대의 요청이 만료되기 전에 서로에게 요청을 보내면**, 별도로
  수락하지 않아도 바로 친구가 됩니다.
- 한 사람당 **동시에 최대 5개**까지만 대기 요청을 가질 수 있고, 그 이상은
  오래된 요청이 만료되거나 응답될 때까지 거절됩니다.
- 거절된 요청은 즉시 사라지지 않고 **TTL이 끝날 때까지 남아 있으므로**,
  거절을 반복해서 자리를 비워 스팸을 보내는 것은 불가능합니다.

## 친구 패널

**F** 키를 누르거나 HUD의 친구 아이콘을 클릭하면 패널이 열립니다. 각
친구 이름 옆에는 **직업 아이콘**(파티 패널과 같은 아이콘 세트이며, 맞는
아이콘이 없으면 글자 배지로 대체)이 표시되고, 다음을 할 수 있습니다:

- **바로 귓속말** — 채팅 입력창에 `/w <이름> `이 자동으로 채워집니다
  (자동으로 전송되지는 않으므로 내용을 수정한 뒤 보낼 수 있습니다).
- **파티 초대** — 기존 파티 초대 흐름을 그대로 사용하므로, 실패 시
  서버가 이유를 알려 주는 방식도 동일합니다.

패널 아래에는 **+ Add** 버튼도 있어서, 클릭한 뒤 이름을 입력하면
`/friend add <이름>`을 입력한 것과 완전히 같은 요청이 전송됩니다 —
채팅창으로 옮겨갈 필요가 없습니다.

## 온라인 상태는 어떻게 알 수 있나

친구의 온라인 상태는 서버가 밀어 주는 게 아니라 **패널이 직접 물어봅니다**:
패널이 열려 있으면 **15초**마다, 닫혀 있으면 **60초**마다 확인합니다.
"OO님이 접속했습니다" 같은 알림은 **연속된 두 응답을 비교해서** 만들어지므로
클라이언트에만 존재하는 개념이고, 서버는 이런 개념을 갖고 있지 않습니다.

## 친구 삭제하기

```
/friend remove <이름>
```

`/friend delete`도 사용할 수 있습니다. 삭제는 **일방적이며 즉시 양쪽 모두에
적용**됩니다 — 상대의 동의가 필요 없고, 양쪽 목록이 동시에 갱신되며,
재접속하지 않아도 바로 반영됩니다.

## 친구와 차단은 양립할 수 없다

한 사람을 동시에 친구이자 차단 대상으로 둘 수 없습니다:

- **이미 친구인 사람을 차단하면 친구 관계가 즉시 해제됩니다.**
- 차단한 사람에게 보낸 친구 요청은 거절되는데, 이때 뜨는 메시지는
  "요청을 보냈고 아직 응답 대기 중"이라는 메시지와 **완전히 동일**해서,
  상대는 자신이 차단당했다는 사실을 알 수 없습니다.

## 친구 목록 보기

인자 없이 `/friend`만 입력하거나 `/f`만 입력하면 현재 친구 목록이 표시됩니다.
