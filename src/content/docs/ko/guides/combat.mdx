모든 판정은 **서버에서** 이루어집니다. 클라이언트는 「이 몬스터를 공격하겠다」만
보내고 결과는 서버가 정합니다.

## 명중 판정

**폭발 20면체 주사위**를 굴립니다:

```
굴림 합계 + 명중 보너스 >  대상 Guard   →  명중
굴림 합계 + 명중 보너스 ≤  대상 Guard   →  빗나감
```

**초과**여야 합니다. 굴린 값이 Guard와 정확히 같으면 **빗나갑니다.**

**명중 보너스**:

- 플레이어 = `floor(레벨 / 2)` + **STR 보정값** + 무기 강화 `+N`
- 몬스터 = **레벨 그대로**(절반 아님) — 플레이어보다 가파릅니다. 플레이어의
  Guard는 레벨이 아니라 장비로 오르기 때문입니다. `monsters.csv`에
  `attackBonus`가 지정돼 있으면 그 값을 기본값 대신 쓰고, 아래의 **장소
  명중 보너스**가 그 위에 더해집니다.

### 장소 명중 보너스

플레이어 Guard는 상한이 없어 장비와 강화만으로 얼마든지 올라가지만, 몬스터
명중 보너스는 레벨이라 최대 20에서 멈춥니다 — 28만큼 벌어진 격차는 20칸짜리
d20 하나로는 감당이 안 됩니다. 그래서 난이도는 몬스터 자체가 아니라 **어디서
싸우느냐**로 조절합니다:

```
던전: 보너스 = max(0, 깊이 − 5) × 3
지상: 보너스 = max(0, 마을과의 거리 − 300m) / 20m
```

- 몬스터의 레벨·체력·피해·경험치는 전혀 바뀌지 않고, 명중 보너스만
  올라갑니다.
- **안전 구간은 기존 난이도를 그대로 유지**합니다 — Old Crypt 1~5층과
  마을 반경 300m는 보너스가 0입니다.
- 그 결과 깊은 던전과 마을에서 먼 야외는 눈에 띄게 어려워집니다 — 그런
  구역에서는 강화 주문서([강화 시스템](../enchant/) 참고)가 있으면 좋은
  것에서 사실상 입장료로 바뀝니다.

### 폭발 주사위란

d20을 굴려 **20이 나오면 한 번 더 굴려서 더합니다.** 그 굴림도 20이면 또
더합니다(최대 5회 — 합계 120이면 어떤 Guard보다도 높습니다).

```
굴림 13          →  합계 13
굴림 20, 10      →  합계 30
굴림 20, 20, 4   →  합계 44
```

**이유.** "자연 20이면 무조건 명중"으로 두면 명중률이 정확히 5%에서
고정됩니다 — 이건 밸런스 판단이 아니라 주사위 면이 20개라서 생기는
숫자일 뿐입니다. 아무리 두꺼운 갑옷을 입어도 코볼트가 스무 번에 한 번은
맞히게 되죠. 폭발 주사위는 **모자란 만큼 확률이 줄어들되 0은 되지 않게**
합니다 — 격차가 20을 넘을 때마다 확률이 다시 1/20로 꺾입니다. 코볼트(+1)가
Guard 40을 맞힐 확률은 0.25%로, 평균 400번에 한 번 — 공격 쿨다운 1.9초
기준 13분입니다. 자연 1은 특별 취급하지 않습니다.

## 피해

명중했을 때만 피해를 굴립니다. 주사위 표기는 `{개수}d{면수}`입니다:

```
2d6  →  6면체 두 개를 굴려 합산(2–12)
```

플레이어의 근접 피해에는 **STR 보정값**이 더해집니다.

### 무기 피해 대조표

<FilterTable
  placeholder="무기 검색…"
  columns={[
    { key: 'name', label: '무기' },
    { key: 'dice', label: '피해 주사위', align: 'center' },

    .map((i) => {
      const [n, sides] = i.dice.split('d').map(Number);
      return {
        name: itemName(i.id), dice: i.dice, min: n,

STR 보정값은 **명중할 때마다** 더해지므로, 피해가 낮은 무기일수록 상대적 상승폭이
큽니다: STR 18(+4)로 단검(1d4, 평균 2.5)을 쓰면 실제 평균은 6.5로 2.6배가 됩니다.

## Guard의 의미

Guard는 NetHack의 AC를 뒤집은 값입니다 — **높을수록 좋습니다.**

| Guard | 의미 |
|---|---|
| 0–7 | 거의 무방비 |
| 8–9 | 방어가 약함 |
| 10 | 보통 |
| 11–13 | 단단함 |
| 14+ | 중장갑 이상 |

NetHack과의 대응: `Guard = 10 − AC`.

## 경험치

### 몬스터를 잡으면 얼마

```
XP = 1 + 레벨² + max(Guard - 10, 0) × 2
```

Guard가 10을 넘는 만큼 보너스가 붙습니다 — **잡기 어려운 몬스터가 더 많이 줍니다.**

  placeholder="몬스터 검색…"
  columns={[

    { key: 'level', label: '레벨', align: 'right' },

      xp: monsterXp(m.level, m.guard), hp: m.healthEffective,

/>

**XP / 체력** 열이 효율 지표입니다 — 클수록 체력 1점을 깎을 때 얻는 경험치가 많습니다.
오크 워로드는 XP가 가장 높지만 120이나 되는 체력을 깎아야 해서 효율은 최고가
아닙니다.

### 레벨업에 필요한 양

2~50레벨은 이제 **플레이 시간** 기준으로 맞춘 구간표를 따르며(
[업데이트 로그](../../updates/) 프로토콜 v39 참고), 순수 지수 곡선이 아닙니다 —
**50레벨을 넘어야 다시 "매 레벨 두 배"**가 됩니다:

```
XP(n) = XP(50) × 2^(n-50)      (n > 50)
```

표는 하루 4시간 플레이하는 표준 유저를 기준으로 잡았습니다: 2~10레벨은
레벨당 5분에서 22분(누적 2시간), 10~30레벨은 22분에서 5.5시간(대략 하루
한 번), 30~50레벨은 5.5시간에서 8시간(후반은 이틀에 한 번쯤)이며, 50레벨
도달까지 총 약 199.5시간(50일)이 걸립니다.

<FilterTable
  placeholder="레벨 입력…"
  columns={[
    { key: 'level', label: '레벨', align: 'right' },
    { key: 'total', label: '누적 XP', align: 'right' },
    { key: 'band', label: '이 레벨에 필요', align: 'right' },
    { key: 'orcs', label: '오크 몇 마리쯤', align: 'right' },
  ]}
  rows={Array.from({ length: 50 }, (_, n) => n + 1).map((level) => {
    const orcXp = monsterXp(4, 11);
    const band = level === 1 ? 0 : xpForLevel(level) - xpForLevel(level - 1);
    return {
      level,
      total: xpForLevel(level).toLocaleString(),
      band: level === 1 ? '—' : band.toLocaleString(),
      orcs: level === 1 ? '—' : Math.ceil(band / orcXp).toLocaleString(),
    };
  })}
/>

맨 오른쪽 열은 오크(레벨 4, Guard 11, 마리당 {monsterXp(4, 11)} XP) 기준입니다.
야외 로스터는 15레벨 독안거인(Cyclops)에서 끝나고 던전 깊이 보정도 20층에서
멈추기 때문에, 실제 페이스는 대략 15~20레벨까지만 표와 맞고 그 위로는 더
강한 상대가 없어 표보다 훨씬 느려집니다.

## 사망 페널티

죽어도 **장비는 잃지 않지만** 경험치가 깎입니다:

```
현재 레벨 구간 = XP(L+1) - XP(L)
차감량        = max(1, floor(구간 × 0.15))
```

즉 **현재 레벨 진행도의 15%**입니다.

### 레벨이 떨어지나

깎은 뒤 XP가 현재 레벨의 시작치보다 낮아지면 **한 레벨 떨어집니다.**
다만 보호 장치가 둘 있습니다:

- **한 번 죽어서 최대 한 레벨만** 떨어집니다.
- **레벨 1은 떨어지지 않습니다.**

레벨이 떨어지면 XP가 아래 구간의 **30% 진행도**로 보정됩니다 —
승급 직전에서 계속 맴도는 상황을 막기 위해서입니다.

<FilterTable
  placeholder="레벨 입력…"
  columns={[
    { key: 'level', label: '레벨', align: 'right' },
    { key: 'band', label: '레벨 구간', align: 'right' },
    { key: 'penalty', label: '사망 차감', align: 'right' },
    { key: 'orcs', label: '오크 몇 마리로 회복', align: 'right' },
  ]}
  rows={Array.from({ length: 12 }, (_, n) => n + 2).map((level) => {
    const band = xpForLevel(level + 1) - xpForLevel(level);
    const penalty = Math.max(1, Math.floor(band * 0.15));
    return {
      level, band: band.toLocaleString(), penalty: penalty.toLocaleString(),
      orcs: Math.ceil(penalty / monsterXp(4, 11)).toLocaleString(),
    };
  })}
/>

### 레벨이 떨어지면 체력도 줄어듭니다

「레벨업/다운을 반복해 체력을 불리는」 짓을 막기 위해, **레벨이 떨어질 때 깎이는
체력의 분포가 레벨업 때 오르는 분포와 완전히 같습니다**:

```
생명 주사위를 굴리고, 최소 절반을 보장한 뒤, CON 보정값을 더한다
```

그래서 장기 기댓값이 **0**입니다 — 오르내림을 반복해도 통계적 이득이 없습니다.
체력이 레벨 1의 초기값 아래로 내려가지도 않습니다.

  placeholder="생명 주사위 검색…"

    hd: `d${hd}`,

/>

**레벨이 떨어지지 않았다면 체력은 깎이지 않습니다.**

## 부활

죽은 뒤 부활을 요청하면 서버가 체력이 0인지 확인하고 가득 채운 뒤 원점 `(0, 0, 0)`으로
보냅니다. 포만도는 300(든든함 구간의 하한)으로 초기화되어, 굶은 채로 부활해 바로
쇠약해지는 일이 없습니다.

### 불사조 부적: 쓰러진 자리에서 부활

가방에 불사조 부적이 있으면 사망 대화상자에 "불사조 부적 사용" 버튼이 추가됩니다.
사용하면 **쓰러진 자리, 같은 층에서** 부활하며 최대 체력의 **70%**를 회복하고
부적 1개를 소모합니다. 사망 시 이미 적용된 경험치 페널티는 그대로입니다. 마을로
돌아가는 일반 부활과 달리 제자리 부활은 포만도를 초기화하지 **않으며**, 부활 후
무적 시간도 없습니다. 살아 있을 때 사용하면 거절되고 부적은 소모되지 않습니다.
Rica가 5,000동에 판매하며, 월드 드랍 확률은 0.2%입니다.

## 몬스터 AI

몬스터 AI는 클라이언트가 계산하지만 **공격 판정은 반드시 서버가 정합니다.**

| 상태 | 설명 |
|---|---|
| `idle` | 대기(30% 확률로 무작위 이동) |
| `walk` | 이동 중 |
| `run` | 플레이어 추적(추적 거리 안) |
| `attack` | 공격 중(공격 거리 안) |
| `hit` | 피격 경직(약 800밀리초) |
| `dead` | 사망 |

몬스터는 죽은 뒤 **30초**가 지나야 사라집니다. 각 몬스터의 추적 거리와 공격 간격은
[몬스터 도감](../../database/monsters/)에 있습니다.

「선제공격」이든 「반격형」이든, 플레이어가 몬스터 **5m** 안에 들어오는 순간
도발 없이도 교전이 시작됩니다 — 「반격형」이라고 안심하고 스쳐 지나갈 수 있는
거리가 아닙니다.

다시 걸리면 지속시간만 갱신되지만, 서로 다른 디버프는 동시에 걸릴 수 있고
배수는 곱해서 적용됩니다.
