낚시는 게임의 첫 채집 직업이자 **스킬 레벨** 시스템을 처음 쓰는 콘텐츠입니다.
모든 타이머, 굴림, 판정이 **전부 서버에서** 이루어지고 클라이언트는 표시와 응답만
담당합니다.

어종과 가격 등 수치표는 [낚시 데이터](../../database/fishing/)에 있습니다.
이 페이지는 **어떻게 낚는지**를 다룹니다.

## 전체 흐름

```
캐스팅 ─► 던지는 중 (1초) ─► 대기 (4–12초, 레벨로 단축)
                                 │ 입질 순간에 어종·크기·트로피 여부가 결정됨
                                 ▼
                            입질 (2.5초 + 0.5초 네트워크 유예)
                            │ 제때 챔질       │ 너무 늦음 / 무반응
                            ▼                 ▼
                          파이팅              놓침
              (장력과 스태미나의 연속 줄다리기)
                            │ 스태미나 소진 후 감기  │ 줄 끊김 / 바늘 빠짐
                            ▼                       ▼
                          낚음                    놓침
```

## 준비

**{itemName('fishing_rod')}**({formatCoins(itemsById.get('fishing_rod').basePrice)})를 사서
**주손에 장착**하세요. Rica가 팝니다.

:::note[낚싯대는 던전 상자에서 나오지 않습니다]
전리품이 아니라 사서 쓰는 도구입니다. 상자는 방어구와 장신구만 줍니다.
:::

## 캐스팅

물을 향해 클릭합니다. 조건:

- 주손에 낚싯대 장착
- **지상**일 것(던전에서는 낚시 불가)
- 목표가 **8미터** 이내
- 목표가 **실제로 물일 것** — 수면이 바닥보다 0.1미터 이상 높아야 함

**바다와 강 모두 가능합니다.** 강은 고지대에 있어도 수면이 자기 하상보다 높으므로
내륙 하천에서도 성립합니다. 육지에서는 수면이 지형 아래로 꺼지므로 육지를 클릭하면
그냥 걸어갈 뿐 잘못 던지지 않습니다.

## 대기와 입질

대기 시간은 **4–12초** 균등 분포이고, 낚시 레벨 1당 **2%**씩 짧아집니다
(하한의 절반 아래로는 내려가지 않음).

입질하면 찌가 확실히 가라앉습니다. 챔질할 시간은 **2.5초**이고 여기에 **0.5초**의
네트워크 유예가 더해집니다 — 이것은 **서버 자신의 시계**로 판정하므로 네트워크가
느려도 실제로 눌렀다면 실패로 처리되지 않고, 반대로 클라이언트를 고쳐 창을 늘릴 수도
없습니다.

:::caution[미리 챔질하지 마세요]
입질 **전에** 챔질하면 물고기가 놀라 도망갑니다. 찌가 가라앉은 뒤에 움직이세요.
:::

**챔질 조작**: `SPACE`, 아무 클릭, 또는 휠 튕기기.

## 파이팅

챔질은 시작일 뿐입니다. 파이팅은 서버가 **250밀리초마다**(초당 4회) 시뮬레이션하는
연속 줄다리기입니다.

물고기는 두 상태를 번갈아 갑니다:

| 상태 | 지속 | 설명 |
|---|---|---|
| **런 (Running)** | 2–3.5초(희귀할수록 김) | 세게 당겨 장력이 오름 |
| **휴식 (Resting)** | 0.8–2초 | 숨 고르기, 압력이 약함 |

대부분의 시간을 물고기가 달리므로, 당신은 대체로 압력을 받는 쪽입니다.

### 세 가지 자세

언제든 바꿀 수 있습니다:

| 자세 | 조작 | 장력에 미치는 영향 |
|---|---|---|
| **감기 (REEL)** | 버튼 누르기 / `SPACE` 누르기 / 휠 아래로 | **+14/초** |
| **줄 풀기 (GIVE LINE)** | 버튼 누르기 / `S` 누르기 / 휠 위로 | **−44/초** |
| **버티기 (HOLD)** | 아무것도 안 함 | 자연 감쇠만 |

`ESC`는 감아서 종료(포기)합니다.

### 장력 — 끊어지는 그 줄

화면의 게이지입니다. **100에 도달하면 줄이 끊어지고 물고기가 도망칩니다.**

| 요인 | 변화량 |
|---|---|
| 챔질 순간의 시작 장력 | **30** |
| 물고기가 달릴 때의 당김 | **(20 + 2 × 희귀도) / 초** |
| ↳ 줄이 많이 나갈수록 최대 **×1.3** | |
| ↳ 낚시 레벨 1당 1% 감소, **최대 30%** | |
| 감기 | **+14 / 초** |
| 물고기가 쉴 때의 자연 감쇠 | **−8 / 초** |
| 줄 풀기 | **−44 / 초** |

<FilterTable
  placeholder="어종 검색…"
  columns={[
    { key: 'name', label: '어종' },
    { key: 'rarity', label: '희귀도', align: 'center' },
    { key: 'pull', label: '런 당김', align: 'right' },
    { key: 'pullMax', label: '줄 최대로 나갔을 때', align: 'right' },
    { key: 'pullLv30', label: '레벨 30일 때', align: 'right' },
  ]}
  rows={items
    .filter((i) => i.category === 'fish')
    .sort((a, b) => a.rarityTier - b.rarityTier)
    .map((i) => {
      const pull = 20 + 2 * i.rarityTier;
      return {
        name: itemName(i.id),
        rarity: `★${i.rarityTier}`,
        pull: `${pull} / 초`,
        pullMax: `${(pull * 1.3).toFixed(1)} / 초`,
        pullLv30: `${(pull * 0.7).toFixed(1)} / 초`,
      };
    })}
/>

**시작 장력 30은 일부러 높게 잡은 값입니다** — 챔질하고 가만히 두면 약 1초 만에
안전 구간을 벗어나고 몇 초 뒤 줄이 끊어집니다. 즉시 반응해야 합니다.

:::tip[줄 풀기는 항상 당김을 이깁니다]
줄 풀기의 −44/초는 **가장 강한 당김보다 큽니다**(황금 철갑상어가 줄을 최대로
빼도 39/초). 그래서 장력이 터지기 직전이라도 줄을 풀면 반드시 내려갑니다 —
대가는 줄이 더 나가서 다음 당김의 배율이 커지는 것입니다.
:::

**감기의 +14는 휴식 시 감쇠 −8보다 큽니다.** 그래서 **감기를 계속 누르고 있을 수는
없습니다** — 감기와 압력 빼기를 오가게 만드는 의도적인 설계입니다.

### 스태미나 — 실제로 깎아야 하는 것

**스태미나는 게이지에 표시되지 않지만** 물보라의 세기로 읽을 수 있습니다 —
물보라가 작아질수록 물고기가 지친 것입니다.

스태미나 총량: `38 + 12 × 희귀도`

**당김만이 스태미나를 소모하며**, 조건이 둘입니다: 물고기가 **런** 중이고,
장력이 **20 이상**일 것.

```
초당 소모 = 2 + 12 × (장력 / 100)²
```

**제곱**이라는 점이 이 시스템의 핵심입니다:

<FilterTable
  placeholder="장력 입력…"
  columns={[
    { key: 'tension', label: '장력', align: 'right' },
    { key: 'drain', label: '초당 소모', align: 'right' },
    { key: 'minnow', label: '피라미 (50)', align: 'right' },
    { key: 'trout', label: '송어 (74)', align: 'right' },
    { key: 'sturgeon', label: '황금 철갑상어 (98)', align: 'right' },
  ]}
  rows={[20, 30, 40, 50, 60, 70, 80, 90, 95].map((t) => {
    const drain = 2 + 12 * (t / 100) ** 2;
    const secs = (pool) => `${(pool / drain).toFixed(0)}초`;
    return {
      tension: t, drain: `${drain.toFixed(2)}`,
      minnow: secs(38 + 12 * 1), trout: secs(38 + 12 * 3), sturgeon: secs(38 + 12 * 5),
    };
  })}
/>

**장력 30으로 황금 철갑상어를 잡으려면 32초, 장력 90이면 8초 — 4배 차이입니다.**

게다가 위 표는 「물고기가 달리고 장력이 조건을 넘긴」 **순수 압박 시간**만 계산한
것이라 실제 소요는 더 깁니다. 물고기가 주기적으로 쉬기 때문입니다.
더 중요한 건 **줄이 느슨하면 쉬고 있는 물고기가 스태미나를 회복한다는 것** —
소극적으로 줄만 풀면 느린 정도가 아니라 뒷걸음질입니다.

### 그래서 올바른 방법은

**장력을 높게 유지하되 터뜨리지 않는 것.** 구체적으로는:

1. 챔질 후 장력은 30에서 시작하고, 물고기는 대개 곧바로 달리기 시작합니다.
2. **감기**로 장력을 밀어 올려 80–95 구간에 둡니다.
3. 게이지를 보다가 100에 가까워지면 **줄을 풀어** 압력을 뺍니다
   (−44/초라 1초면 안전 구간으로 돌아옵니다).
4. 60–70 정도까지 내려오면 줄 풀기를 멈추고 다시 감아 올립니다.
5. 물고기가 **쉴 때**가 거리를 좁힐 기회입니다 — 당김이 약하고 감는 속도도 빠릅니다.

초보자가 가장 흔히 하는 실수는 **처음부터 끝까지 줄만 풀며 버티는 것**입니다 —
장력이 20–30에 머물면 스태미나가 거의 안 깎이고, 물고기가 쉴 때는 오히려 회복해서
3분을 싸워도 제자리입니다.

### 거리와 마무리

거리는 숫자로 표시되지 않습니다 — **찌가 곧 물고기의 위치**입니다.

| 상황 | 감는 속도 |
|---|---|
| 물고기가 쉬는 중 | 1.6 m/s |
| 물고기가 달리는 중 | 0.6 m/s |
| 물고기가 탈진 | 2.5 m/s |

달릴 때는 초당 1.1–1.5미터의 줄이 나가지만, 캐스팅 지점에서 **6미터를 벗어나지는
않습니다.**

스태미나가 0이 되면 물고기는 **탈진(Exhausted)** 상태가 되고,
이때 「줄 바닥」 부근(0.3미터 이내)까지 감으면 낚입니다.

:::caution[힘이 남은 물고기를 억지로 끌면 안 됩니다]
스태미나가 남은 물고기를 1미터 이내로 끌어당기면 **놀라서 다시 달립니다.**
반드시 스태미나를 다 뺀 다음에 감으세요.
:::

## 낚시가 중단되는 조건

**중단됨**: 이동, 공격, 접속 끊김, 사망, 낚싯대를 치움(해제하거나 주손에 무기를
바꿔 끼움), 직접 중지.

**중단 안 됨**: 모자 바꾸기, 보조손에 횃불 들기 — 낚싯대가 주손에 남아 있으면
집중이 깨진 것으로 보지 않습니다.

## 낚시 레벨

조과물은 **낚시 경험치**를 줍니다: `10 × 희귀도²`

<FilterTable
  placeholder="어종 검색…"
  columns={[
    { key: 'name', label: '조과물' },
    { key: 'rarity', label: '희귀도', align: 'center' },
    { key: 'xp', label: '낚시 XP', align: 'right' },
  ]}
  rows={items
    .filter((i) => i.catchWeight !== null)
    .sort((a, b) => b.rarityTier - a.rarityTier)
    .map((i) => ({
      name: itemName(i.id),
      rarity: i.rarityTier === 0 ? '잡동사니' : `★${i.rarityTier}`,
      xp: i.rarityTier === 0 ? '0' : 10 * i.rarityTier ** 2,
    }))}
/>

- 걸었다가 **놓쳐도** 위로 경험치 **2**를 줍니다. 놓쳤을 때는 **무슨 물고기였는지
  알려주지 않습니다** — 위로 경험치가 어종마다 달라지면 숨겨둔 굴림 결과가 새기
  때문입니다.
- 잡동사니는 희귀도 0이라 **경험치가 전혀 없습니다.**
- **낚시는 캐릭터 경험치를 주지 않습니다** — 전투 밸런스에 전혀 영향이 없습니다.

### 레벨의 실제 효과

| 효과 | 레벨당 | 상한 |
|---|---|---|
| 대기 시간 단축 | −2% | 하한의 절반 |
| 희귀 어종 가중치 상승 | +3% / 희귀도 1당 | 없음(곱연산이라 순서는 안 뒤집힘) |
| 받는 당김 감소 | −1% | **−30%** |
| 감는 속도 상승 | +1% | — |

**레벨 10**에서 강 연어, **레벨 20**에서 황금 철갑상어가 해금됩니다.
레벨이 안 되면 아예 나오지 않습니다.

그래서 입질 순간의 긴장감은 진짜입니다 — 끌어올린 게 황금 철갑상어일지 장화일지
알 수 없으니까요.

## AI 에이전트도 낚을 수 있습니다

이 시스템은 **사람과 에이전트 모두 가능하도록** 의도적으로 설계되었습니다 —
2.5초의 반응 창은 에이전트의 네트워크 왕복에도 무리가 없는 크기이고,
파이팅 시뮬레이션이 초당 4회만 진행되므로 「반응이 빠른 것」이 실질적인 이점이
되지 않습니다.

데스크톱 클라이언트의 자동 모드는 스스로 챔질하고 자세를 바꾸며,
LLM은 「낚을지, 어디서 낚을지」만 결정합니다.
