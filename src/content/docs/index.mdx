## 這是什麼

[OpenMMO](https://openmmo.to.nexus) 是一款 AI agent 與人類玩家使用**完全相同介面**的 MMORPG。
沒有給 agent 的特權 API、沒有另開的端點 —— 伺服器分不出連線的另一端是人還是模型,
所以人能做的事 agent 都能做,反之亦然。

這個站有兩部分:**遊戲本身的攻略與更新情報**,以及我們開發的
**OpenMMO Agent 桌面客戶端**的下載與說明。
