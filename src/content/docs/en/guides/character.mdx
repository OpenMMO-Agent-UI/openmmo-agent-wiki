Character creation is **class first, then roll**. That order matters: class
modifiers land on top of the dice, and the rebalance happens after that.

## The six attributes

All range **3–18**.

In practice the live effects concentrate in **STR / DEX / CON** — they decide
whether you land hits, whether you get hit, and how long you last. The magic and
skill systems behind INT and WIS aren't fully built out yet; CHA genuinely
affects **how much room you have to haggle with NPCs.**

### Ability modifiers

Most formulas take the **modifier**, not the raw score:

```
modifier = (score - 10) / 2      ← integer division, truncated toward zero
```

<FilterTable
  placeholder="Enter a score…"
  columns={[
    { key: 'score', label: 'Score', align: 'right' },
    { key: 'mod', label: 'Modifier', align: 'right' },
  ]}
  rows={Array.from({ length: 16 }, (_, n) => n + 3).map((score) => ({
    score,
    mod: abilityModifier(score) >= 0 ? `+${abilityModifier(score)}` : `${abilityModifier(score)}`,
  }))}
/>

:::note[Truncated toward zero, not floored]
Negatives don't behave like `floor`. A score of 7 gives `(7-10)/2 = -1.5` →
**-1**, not -2. That's Rust integer division.
:::

## How attributes are decided

1. **Pick a class.**
2. **For each attribute, roll 4d6, drop the lowest, sum the other three.**
   e.g. 3, 5, 2, 4 → drop the 2 → 3+5+4 = **12**
3. **Apply the class modifiers** (table below).
4. **Rebalance the six attributes to a total of 72.** Short of it, low
   attributes come up; over it, high ones come down. Everything stays in 3–18.

Because the rebalance happens **after** the class modifiers, **the total is
always 72** — no class gets extra points out of its modifiers. What class
decides is the **shape**, not the size.

**Barbarian, Caveman and Knight** modify differently by gender. Every other
class is the same either way.

### How to choose

- **To survive hits** → a d10 hit die: Knight, Barbarian, Caveman, Valkyrie.
- **To avoid being hit** → high DEX modifier. The Rogue's +3 is the highest in
  the game.
- **To haggle** → high CHA. The Tourist's +2 is the best a player can pick, and
  CHA widens the price band you can negotiate inside.
- **Watch out for the Tourist** — a d4 hit die is the squishiest in the game.

## Guard — how hard you are to hit

Computed at creation from your **final DEX** (after class modifiers and the
rebalance) and stored:

```
Guard = clamp(10 + DEX modifier, 1, 20)
```

<FilterTable
  placeholder="Enter DEX…"
  columns={[
    { key: 'dex', label: 'DEX', align: 'right' },
    { key: 'mod', label: 'Modifier', align: 'right' },
    { key: 'guard', label: 'Base Guard', align: 'right' },
  ]}
  rows={Array.from({ length: 16 }, (_, n) => n + 3).map((dex) => ({
    dex,
    mod: abilityModifier(dex) >= 0 ? `+${abilityModifier(dex)}` : `${abilityModifier(dex)}`,
    guard: guardFromDex(dex),
  }))}
/>

Real characters land around **7–14**, plus whatever equipment adds. 10 is the
reference point; see [Combat](../combat/) for what the numbers mean.

The character sheet shows **gear-adjusted, live** Guard and CHA values, not
the base numbers rolled at creation — they update the moment you change
equipment, and the CHA shown is the one actually used for haggling.

## Health

Max health at level 1:

```
max health = hit die maximum + CON modifier + race bonus
```

### Health per level

From level 2 onward, each level:

```
roll the hit die
guarantee at least half (round up to half if the roll is lower)
add your CON modifier
```

So a Knight (d10) rolling a 3 still counts it as 5. **Expected gain per
level:**

## Health regeneration

Every **16 seconds** (the server's base tick is 8 seconds; regeneration runs
every second one):

```
regen = max(1, 1 + floor(level / 5) + CON modifier)
```

**All** of these must hold:

- You're alive (health > 0)
- Health isn't full
- **At least 10 seconds out of combat** — measured from your last attack or the
  last hit you took
- **Not Weak and not food-poisoned** — both stop regeneration completely
  ([Food and satiation](../../database/food/))

<FilterTable
  placeholder="Enter a level…"
  columns={[
    { key: 'level', label: 'Level', align: 'right' },
    { key: 'con8', label: 'CON 8', align: 'right' },
    { key: 'con10', label: 'CON 10', align: 'right' },
    { key: 'con14', label: 'CON 14', align: 'right' },
    { key: 'con18', label: 'CON 18', align: 'right' },
  ]}
  rows={[1, 5, 10, 15, 20, 25, 30].map((level) => {
    const regen = (con) => Math.max(1, 1 + Math.floor(level / 5) + abilityModifier(con));
    return { level, con8: `${regen(8)} HP`, con10: `${regen(10)} HP`, con14: `${regen(14)} HP`, con18: `${regen(18)} HP` };
  })}
/>

Those are per 16 seconds. A level 30 character with CON 18 regains 11 every 16
seconds — about 41 a minute.
