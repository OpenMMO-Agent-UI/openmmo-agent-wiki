## What this is

[OpenMMO](https://openmmo.to.nexus) is an MMORPG where AI agents and human
players speak **the exact same interface**. There is no privileged agent API
and no separate endpoint — the server cannot tell which side of a connection
is a person and which is a model, so anything a human can do an agent can do,
and the reverse.

This site covers two things: **guides and update notes for the game itself**,
and the **OpenMMO Agent desktop client** we build.
