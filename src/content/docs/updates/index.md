遊戲更新以**協議版本**為主軸整理 —— 因為伺服器精確比對協議版本,
協議一變,舊的客戶端就連不上了。所以這條軸線同時回答兩個問題:
「遊戲改了什麼」以及「我需不需要重新下載客戶端」。

## 分類方式

| 標記 | 意思 |
|---|---|
| 新系統 | 新增的玩法機制 |
| 平衡調整 | 數值、經濟、掉落率的變動 |
| 新道具與素材 | 新武器、防具、模型、音樂 |
| 修正 | 錯誤修復 |
| 效能 | 執行效率與載入速度 |
| 客戶端 | 只影響桌面客戶端,與遊戲伺服器無關 |

## 尚未進入客戶端版本的變更

以下已經在遊戲伺服器上,但還沒對應到已發佈的客戶端版本。

**平衡調整**

- **口糧全面重新調整**(2026-08-04)。麵包成為「一天一餐」的主力,肉乾改走輕便路線:

  | 食物 | 飽食度 | 重量 | 價格 |
  |---|---:|---:|---:|
  | 麵包 | 180 → **540** | 0.5 → **1 kg** | 8c → **20c** |
  | 肉乾 | 540 → **300** | 0.5 → **0.25 kg** | 40c → **30c** |
  | 起司 | 300 → **180** | 0.5 → **0.4 kg** | 20c → **12c** |
  | 蘋果 | 60(不變) | 0.3 kg | 3c |

  完整效率對照見[食物與飽食度](../database/food/)。

**新系統**

- **HUD 小地圖**,顯示在時間元件下方(可關閉)。地標與世界地圖標記一併改善。
- **管理指令**:`/kick`、`/mute`、`/summon`、`/goto`。

**修正**

- 同一帳號只允許一個連線工作階段。
- 拒絕刪除正在其他工作階段使用中的角色。
- 伺服器端強制玩家攻擊間隔。
- 地城寶箱歷史無法載入時拒絕進入遊戲(fail-closed)。
- 隊伍位置改為主動推送,不再由各客戶端輪詢 —— 也不會再吵醒 agent。

## 協議 v16 —— 對應客戶端 v0.17.0

**新系統**

- **飢餓與飽食系統**,端到端實作。角色狀態頁新增飢餓效果分頁,
  HUD 顯示飽食度與說明提示。
- **營火系統**重做 —— 取代原本的程序生成營火,並調整了火焰表現與擺放判定。
- 食物可以用營火**燒烤**(道具資料中的 `grillsInto` 欄位)。

**平衡調整**

- **道具經濟全面重新平衡**,並整理出完整的武器階級階梯。
- 環境怪物的生成改為**需要伺服器配額**,不再由客戶端自行決定。
- 怪物掉落物改由**伺服器保留到致命一擊落下**才產生,避免搶奪與重複。

**新道具與素材**

- `ring_of_protection`(防護戒指),搭配十字盾戒指的飾品模型。
- 匕首取得專屬模型與圖示。
- 華麗十字腰帶模型與圖示。

**其他**

- 世界地圖會**記錄你已經發現的地城入口**。
- 組隊邀請顯示**倒數計時條**,不再只是靜態訊息。
- 火把粒子效果修正。
