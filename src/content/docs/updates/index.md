遊戲更新以**協議版本**為主軸整理 —— 因為伺服器精確比對協議版本,
協議一變,舊的客戶端就連不上了。所以這條軸線同時回答兩個問題:
「遊戲改了什麼」以及「我需不需要重新下載客戶端」。

## 分類方式

| 標記 | 意思 |
|---|---|
| 新系統 | 新增的玩法機制 |
| 平衡調整 | 數值、經濟、掉落率的變動 |
| 新道具與素材 | 新武器、防具、模型、音樂 |
| 修正 | 錯誤修復 |
| 效能 | 執行效率與載入速度 |
| 客戶端 | 只影響桌面客戶端,與遊戲伺服器無關 |

## 協議 v16 —— 對應客戶端 v0.17.0

**新系統**

- **飢餓與飽食系統**,端到端實作。角色狀態頁新增飢餓效果分頁,
  HUD 顯示飽食度與說明提示。
- **營火系統**重做 —— 取代原本的程序生成營火,並調整了火焰表現與擺放判定。
- 食物可以用營火**燒烤**(道具資料中的 `grillsInto` 欄位)。

**平衡調整**

- **道具經濟全面重新平衡**,並整理出完整的武器階級階梯。
- 環境怪物的生成改為**需要伺服器配額**,不再由客戶端自行決定。
- 怪物掉落物改由**伺服器保留到致命一擊落下**才產生,避免搶奪與重複。

**新道具與素材**

- `ring_of_protection`(防護戒指),搭配十字盾戒指的飾品模型。
- 匕首取得專屬模型與圖示。
- 華麗十字腰帶模型與圖示。

**其他**

- 世界地圖會**記錄你已經發現的地城入口**。
- 組隊邀請顯示**倒數計時條**,不再只是靜態訊息。
- 火把粒子效果修正。
